# 时间裂缝

Godot 4.7 的经营与防守原型：居民自动采集、运输、建造和生活，玩家发展聚落、训练军队，抵御袭扰与时间裂缝，击败关底 Boss。

当前状态整理于 **2026-10-09**。第一局主线已有用户实测跑通记录；最新功能与完整 40 分钟关卡仍需持续试玩，不能据此认定所有内容均已验收。

## 启动项目

1. 使用 Godot 4.7 打开根目录 `project.godot`；历史测试使用 4.7.2，项目配置为 Forward+ / Windows D3D12。
2. 同步地图插件子模块，等待编辑器首次导入完成。
3. 按 F6 运行当前场景或 F5 运行项目；正式游戏使用项目配置的主场景。

首次下载：

```powershell
git clone --recurse-submodules https://github.com/Qfather/gpt_game.git
```

已有工作副本在拉取后执行：

```powershell
git submodule update --init --recursive
```

地图生成器位于 `addons/MapGenerate`，是独立 Git 子模块，需要相应仓库访问权限。`.godot` 为自动生成的导入缓存。Flow Nodes 插件及其原生扩展已移除，无需携带旧 Flow DLL。

## 当前功能

以下按已有实现与验证记录汇总；具体修改及当时的验证边界见 [开发日志](docs/日志.md)。

| 系统 | 当前能力 |
| --- | --- |
| 经营与建造 | 木材／石料采集、农场粮食生产、本地库存与运输；网格放置、清障、工地材料运输、多人施工、取消、拆除、搬迁与维修。 |
| 居民与人口 | 饥饿／疲劳、饮食喜好、住房和阶段移民；固定住所休息、据点室内待命、建筑门口排队进出、空闲及不可达提醒；移动停滞时重查路径，返回工作建筑或训练营时重新选择正面可达位置。 |
| 军事与狩猎 | 民兵／剑士／弓箭手共用可配置训练流程，驻军、巡逻和补粮；民兵营由蓝图分支升级为剑士营或弓箭手营。猎人认领猎物、射杀、拾取、回屋处理产肉；双人箭塔。 |
| 战斗职责 | 攻击能力与职责分开判断：普通居民避险，攻击标签不会令其自动参战；猎人自卫，剑士／弓箭手主动迎战。单位详情显示职责，猎物处理显示建筑上方进度条。 |
| 警戒与避险 | 箭塔及墙上箭塔由驻守弓箭手监测水平20米内敌人，选中显示警戒范围，进入原有射程才攻击。警报让未受完整城墙保护的非战斗居民回自己的住所，无家则回据点；没有有效警报时，仅受攻击的居民避险。 |
| 城墙防线 | 木桩墙逐格拖拽、绕过已有建筑与六种邻接外观；资源阻挡处可先放蓝图，工人到场后每个资源固定5秒清除、无资源收入，清完再按原时长建造；木墙、木城门、木塔楼可补材料差价升级为石制，石制防线不直接出现在建造菜单；4×1 木城门可半价改建四格直墙；对应墙上建单弓箭手塔楼。城门开关尚未实现。 |
| 战斗与关卡 | 数据驱动敌人、袭扰与裂缝时间线、波次、精英／Boss、据点失败与关底胜利；宝箱营地、守卫与战利品回收。 |
| 地图与视野 | MapGenerate 地形和植被、湿润度地表混合、建筑周边干燥、资源湿润度筛选及再生；昼夜、战争迷雾与火把视野。 |
| 道路与操作 | 土路／石路拖拽、绕障、居民施工及道路优先移动；沿道路按行进方向走右半幅中心，1米道路偏移0.25米，转角连接偏移路线，受阻回退普通导航；自定义单位扫描、跟随减速、绕行和让路已注释停用，保留实体碰撞；对象详情、建筑范围、室内身份人数和训练进度提示。 |
| 内容配置 | 资源、建筑、单位、名称池、特性及关卡编辑入口；建筑插件可复制新增定义，配置等级、蓝图池、前置关联和多个训练配方，保存校验与安全删除。参数自动保存；通用参数只保存配置，专属参数修改后才保存对应场景。 |

T0开局可建伐木场、采石场、农舍、民兵营和住宅；T1猎人小屋、军营、箭塔需各自蓝图后直接建造，剑士营／弓箭手营需蓝图后从民兵营升级。调试HUD提供“抽取建筑蓝图（三选一）”，正式关卡奖励触发尚未接入。具体配置和操作见[建筑蓝图与公共训练](docs/归档/建筑蓝图与公共训练.md)。

未来的建模源文件放在 `bl/`，与游戏运行时资源分开管理；`.blend` 是建模源文件，Godot 导入设置由相邻 `.blend.import` 文件记录。

营地清剿暂不接受正在出门、门口排队或尚未抵达待命站位的单位；过渡完成后可正常分配。撤回任务保留正常的室外碰撞，避免角色恢复为不检测建筑阻挡。

城墙基本体已接入游戏配置；替换模型的场景入口与朝向约定见 [城墙与防线模型配置](docs/归档/城墙与防线模型配置.md)。

主场景与关卡插件默认使用 `data/levels/LevelFlow_40min_Hard.tres`；事件安排见 [40 分钟困难关卡](docs/归档/40分钟困难关卡说明.md)。

## 常用操作

| 操作 | 输入 |
| --- | --- |
| 建筑放置 | 底部选择建筑，左键确认，右键／Esc 取消；R 旋转，M 镜像。火把不可旋转。 |
| 道路铺设 | 底部选择土路／石路，左键拖拽；右键／Esc 取消。 |
| 城墙与改建 | 石墙／木桩墙左键拖拽；城门放在空地全价、对应四格直墙上半价；塔楼只放在对应墙段上。 |
| 选择与详情 | 点击单位、建筑、资源等对象；选中有入口的建筑显示贴地等腰三角形，底边与建筑正面同宽、顶点向前0.3米；双击建筑或居民多选当前可见的同类对象，可批量升级木制防线；点击空地取消选择。 |
| 建筑搬迁 | 选中可搬迁建筑后按 G；未开工蓝图免费搬迁，已开工工地锁定至建成。 |
| 箭塔警戒 | 弓箭手实际驻守后启用20米侦察，至少一人处于驻守状态时有效；全部离塔、进食或休息时暂停。选中显示警戒范围，攻击沿用原射程。独立瞭望塔已移除。 |
| 暂停／速度 | 空格暂停或恢复；数字 1／2／3 切换 1X／2X／3X。暂停时建筑操作立即生效并刷新HUD及详情，角色移动和生产进度保持暂停。 |
| 隐藏界面 | H 切换 HUD 与相关提示。 |
| 相机 | WASD 平移，Q／E 水平旋转，滚轮缩放，中键旋转，Shift＋中键平移。 |
| 对象视角 | F 聚焦选中对象；选中角色后 T 进入／退出旁观视角。 |

`Script/dev_mode.gd` 中 `DevMode.DEV_MODE` 当前为 `true`，开发调试入口可用；正式试玩或发布前按需要关闭。

## 已知限制与待验收

- 完整 40 分钟关卡难度与经济平衡、道路边缘通行及复杂敌情下的操作体验仍需连续试玩。
- 城墙保护按完工防线的闭环判断；缺口、高低差断开、错误城门连接及敌人进入围合区会取消保护。城门目前仍可通行，开关门功能尚未实现。规则与验证见[箭塔警戒与居民避险](docs/归档/箭塔警戒与居民避险.md)。
- 迷雾 CPU 缓存优化已通过像素等价和渲染回归，33 人 / 15 敌人、3 倍速压力测试持续战斗约 45 → 67 FPS；66 人拥挤场景与用户原始第 19 分钟低帧现场仍待解决。详见[压力测试报告](docs/归档/迷雾与袭扰压力测试_2026-10-08.md)。整体启动仍有波动，首个渲染帧等待尚未优化。
- 资源导航回归曾留下“路径结束被误判为实际抵达”“高台敌人未经过坡道抵达低地目标”两项失败，没有后续修复记录。
- 道路尚未接入存档；资源动效编辑器完整排版仍需实际使用确认。
- “居民停在箭塔旁却未修好”的用户现场尚未复现，已有维修测试通过不能代替该现场的确认。
- 编辑器／游戏退出仍有既有 RID 或资源释放警告；角色拉弓动画等表现仍未完成。

以上限制来自已有记录，未逐项重新验收；本轮城墙与道路的验证结果见开发日志。性能依据见 [启动耗时排查](docs/归档/2026-10-05-进入游戏耗时排查.md) 与 [三倍速行走性能排查](docs/归档/2026-10-05-三倍速正常行走性能排查.md)。

## 验证入口

自动测试保存在 `Tests/`。按修改范围选择相关脚本，不把旧测试列表当作全套验收。

```powershell
# 在项目根目录执行，将 godot 替换为本机 Godot 可执行文件路径。
godot --headless --path . --script res://Tests/game_resource_moisture_test.gd
godot --path . --script res://Tests/indoor_idle_rest_test.gd
```

湿润度、建筑干燥、道路资源占地、狩猎及远程战斗的测试分别可从 `game_resource_moisture_test.gd`、`building_surface_drying_test.gd`、`road_resource_clearance_test.gd`、`hunting_ranged_test.gd`、`ranged_retreat_test.gd` 开始查阅。

运行时检查退出码与错误输出；渲染、交互和完整玩法需要有画面的验证。部分历史测试依赖提前生成的 `.godot` 测试资源，不能仅凭脚本存在认定全部可直接运行。
