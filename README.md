# 时间裂缝

Godot 4.7 的经营与防守原型：居民自动采集、运输、建造和生活，玩家发展聚落、训练军队，抵御袭扰与时间裂缝，击败关底 Boss。

当前状态整理于 **2026-10-08**。第一局主线已有用户实测跑通记录；最新功能与完整 40 分钟关卡仍需持续试玩，不能据此认定所有内容均已验收。

## 启动项目

1. 使用 Godot 4.7 打开根目录 `project.godot`；历史测试使用 4.7.2，项目配置为 Forward+ / Windows D3D12。
2. 同步地图插件子模块，等待编辑器首次导入完成。
3. 按 F6 运行当前场景或 F5 运行项目；正式游戏使用项目配置的主场景。

首次下载：

```powershell
git clone --recurse-submodules https://github.com/Qfather/gpt_game.git
```

已有工作副本在拉取后执行：

```powershell
git submodule update --init --recursive
```

地图生成器位于 `addons/MapGenerate`，是独立 Git 子模块，需要相应仓库访问权限。`.godot` 为自动生成的导入缓存。Flow Nodes 插件及其原生扩展已移除，无需携带旧 Flow DLL。

## 当前功能

以下按已有实现与验证记录汇总；具体修改及当时的验证边界见 [开发日志](docs/开发日志.md)。

| 系统 | 当前能力 |
| --- | --- |
| 经营与建造 | 木材／石料采集、农场粮食生产、本地库存与运输；网格放置、清障、工地材料运输、多人施工、取消、拆除、搬迁与维修。 |
| 居民与人口 | 饥饿／疲劳、饮食喜好、住房和阶段移民；固定住所休息、据点室内待命、建筑门口排队进出、空闲及不可达提醒。 |
| 军事与狩猎 | 剑士／弓箭手训练、驻军、巡逻和补粮；猎人认领猎物、射杀、拾取、回屋处理产肉；双人箭塔。 |
| 城墙防线 | 石墙／木桩墙逐格拖拽、自动绕障与六种邻接外观；4×1 石／木城门可半价改建四格直墙；对应墙上建单弓箭手塔楼。已提供可替换的基本体场景，城门开关尚未实现。 |
| 战斗与关卡 | 数据驱动敌人、袭扰与裂缝时间线、波次、精英／Boss、据点失败与关底胜利；宝箱营地、守卫与战利品回收。 |
| 地图与视野 | MapGenerate 地形和植被、湿润度地表混合、建筑周边干燥、资源湿润度筛选及再生；昼夜、战争迷雾与火把视野。 |
| 道路与操作 | 土路／石路拖拽、绕障、居民施工及道路优先移动；对象详情、建筑范围、室内身份人数和训练进度提示。 |
| 内容配置 | 资源、建筑、单位、名称池、特性及关卡编辑入口；参数自动保存，按建筑功能隐藏无关字段；道路支持固定值／百分比加速、共享标准材质与六种连接形态贴图。建筑通用参数只保存配置，专属参数修改后才保存对应场景。 |

未来的建模源文件放在 `bl/`，与游戏运行时资源分开管理；`.blend` 是建模源文件，Godot 导入设置由相邻 `.blend.import` 文件记录。

城墙基本体已接入游戏配置；替换模型的场景入口与朝向约定见 [城墙与防线模型配置](docs/城墙与防线模型配置.md)。

主场景与关卡插件默认使用 `data/levels/LevelFlow_40min_Hard.tres`；事件安排见 [40 分钟困难关卡](docs/40分钟困难关卡说明.md)。

## 常用操作

| 操作 | 输入 |
| --- | --- |
| 建筑放置 | 底部选择建筑，左键确认，右键／Esc 取消；R 旋转，M 镜像。火把不可旋转。 |
| 道路铺设 | 底部选择土路／石路，左键拖拽；右键／Esc 取消。 |
| 城墙与改建 | 石墙／木桩墙左键拖拽；城门放在空地全价、对应四格直墙上半价；塔楼只放在对应墙段上。 |
| 选择与详情 | 点击单位、建筑、资源等对象；点击空地取消选择。 |
| 建筑搬迁 | 选中可搬迁建筑后按 G；未开工蓝图免费搬迁，已开工工地锁定至建成。 |
| 暂停／速度 | 空格暂停或恢复；数字 1／2／3 切换 1X／2X／3X。 |
| 隐藏界面 | H 切换 HUD 与相关提示。 |
| 相机 | WASD 平移，Q／E 水平旋转，滚轮缩放，中键旋转，Shift＋中键平移。 |
| 对象视角 | F 聚焦选中对象；选中角色后 T 进入／退出旁观视角。 |

`Script/dev_mode.gd` 中 `DevMode.DEV_MODE` 当前为 `true`，开发调试入口可用；正式试玩或发布前按需要关闭。

## 已知限制与待验收

- 完整 40 分钟关卡难度与经济平衡、道路边缘通行及复杂敌情下的操作体验仍需连续试玩。
- 历史排查记录中的迷雾刷新尖峰／低帧问题尚未解决；整体启动仍有波动，首个渲染帧等待尚未优化。
- 资源导航回归曾留下“路径结束被误判为实际抵达”“高台敌人未经过坡道抵达低地目标”两项失败，没有后续修复记录。
- 道路尚未接入存档；资源动效编辑器完整排版仍需实际使用确认。
- “居民停在箭塔旁却未修好”的用户现场尚未复现，已有维修测试通过不能代替该现场的确认。
- 编辑器／游戏退出仍有既有 RID 或资源释放警告；角色拉弓动画等表现仍未完成。

以上限制来自已有记录，未逐项重新验收；本轮城墙与道路的验证结果见开发日志。性能依据见 [启动耗时排查](docs/2026-10-05-进入游戏耗时排查.md) 与 [三倍速行走性能排查](docs/2026-10-05-三倍速正常行走性能排查.md)。

## 验证入口

自动测试保存在 `Tests/`。按修改范围选择相关脚本，不把旧测试列表当作全套验收。

```powershell
# 在项目根目录执行，将 godot 替换为本机 Godot 可执行文件路径。
godot --headless --path . --script res://Tests/game_resource_moisture_test.gd
godot --path . --script res://Tests/indoor_idle_rest_test.gd
```

湿润度、建筑干燥、道路资源占地、狩猎及远程战斗的测试分别可从 `game_resource_moisture_test.gd`、`building_surface_drying_test.gd`、`road_resource_clearance_test.gd`、`hunting_ranged_test.gd`、`ranged_retreat_test.gd` 开始查阅。

运行时检查退出码与错误输出；渲染、交互和完整玩法需要有画面的验证。部分历史测试依赖提前生成的 `.godot` 测试资源，不能仅凭脚本存在认定全部可直接运行。
