### 道路、建筑与编辑器

- 拖拽两点自动寻找绕开建筑、资源的四向连续平地道路；无法连通或整条新路材料不足时整条预览变红，松开不生成截断道路。
- 铺路先标记黄色待施工格，由空闲普通居民按距离领取可达任务，每格只允许一人施工，到达后才计时，暂停停止施工。土路免费、每格 3 秒；石路新建／升级每格 5 秒，默认消耗 1 石头。成本、施工时间和移速倍率读取建筑编辑器配置；升级期间保留原土路效果，新路完工前不提供道路加速或道路优先寻路。
- 材料在标记时从据点扣除，拆除不返还；批量升级底层保留按库存部分标记的行为。道路仍按 8×8 格合并网格，没有逐格工地节点，也不因铺路重新烘焙地形导航。
- HUD 选择土路／石路后直接拖拽，移除额外道路操作面板；拖拽石路经过土路可标记升级，右键／Esc 取消。确认铺路时清理同高度路格中的簇散布花草、装饰石子，保留邻格和可采集树木／石矿；预览与无效操作不清理。
- 建筑编辑器增加生产／军事／战略／道路／加工标签，通用属性增加分类下拉与排序 ID；游戏 HUD 使用相同配置，ID 越小越靠前，相同 ID 按稳定 ID 排序。土路和石路可以单独编辑，加工分类目前为空，据点不加入玩家建造菜单。
- 建筑材料读取配置，住宅当前木材需求为 10；编辑器修改后需点击“保存建筑与专属参数”并重新运行。已开工工地保留开工时需求，HUD 与工地文字支持小数材料值。
- 关卡地图资源增加可复用的受击动效：无／旋转回弹／位移回弹／缩放回弹，每种分别保存幅度、受击时间和恢复时间；支持模型预览与预览受击。树木默认旋转、石头默认位移，只动外观，不改变碰撞／导航，连续受击可重播并精确归位；修复参数与预览按钮文字重叠。
- 移除未使用的 Flow Nodes 插件、Flow 原生扩展及专用测试；游戏关卡时间线 `LevelFlowData` 保留。关卡插件仍启用，新增“项目 → 工具 → 关卡编辑器”入口以重新显示面板；旧转接文档的 Flow DLL 携带要求不再适用。

### 通行、居民与战斗行为

- 普通建筑、树木和石头实体碰撞的 X／Z 缩至原范围的 50%，保留高度、独立点击范围与建造／资源占地；城墙和城门沿用原规则。保留导航 0.75m 角色余量，两栋房屋间一格道路能够连通，单位仍不能横穿建筑中心。
- 浅蓝移民使用投影后的可达交互点统一导航和抵达判定，抵达后停止移动，倍速单步不越过路径点，修复路端左右晃动的复现案例。
- 移民先到据点正门，再走入室内才转换为居民、增加正式人口，随后从同一扇门走出；保留姓名与特质，出入门期间不接受任务，出门后恢复碰撞与正常工作。入口／室内位置由据点场景标记定义。
- 箭塔相关状态文字改为“箭塔”。修复弓箭手因途中吃饭／休息丢失预约而卡在塔下：中断期间保留驻扎预约，旧预约丢失时在入口按职业与容量重新登记；已验证双人分别上塔及满塔拒绝第三人。
- 工作建筑附近或异地待机、等待任务材料、抵达工地后等待均显示头顶感叹号；无职业无任务居民在据点待机区内不提示。空闲与不可达分别判定，恢复工作清除提醒，迷雾隐藏区域不泄露标记。
- 居民各职业与怪物沿最短角度平滑转向移动／采集／攻击目标，以每秒 450° 转动：90° 用 0.2 秒，180° 用 0.4 秒；正后方固定选择同一侧，停下后保留朝向，转身期间继续移动。只旋转外观外层 `VisualRoot`，转职保留朝向，碰撞、寻路与模型内部动画独立。替换模型统一 +Z 为正面、+Y 为上方；未来根运动需要另行协调。

### 性能优化与文档整理

以下数据来自本机受控测试，分别衡量对应步骤，不能直接作为整局 FPS 或固定启动时间保证。

| 优化项 | 修改与实测结果 |
| --- | --- |
| 拖拽道路预览 | 初始化四向连接图，复用原生寻路与动态障碍缓存；路径／状态未变时不重建网格。568 个资源、30 次查询，平均约 236ms → 1.9ms。 |
| 正常播放中铺路 | 同帧施工占地检查共享资源缓存，建筑仍实时检查；300 次检查约 614ms → 46ms。116 格待建道路并拖拽的 GPU 对照，整帧中位耗时约 76ms → 14ms。 |
| 开局道路初始化 | 缓存地形格坐标和可建造性，替换高度资源时失效；道路预览图初始化约 3,300ms → 325–327ms。 |
| 资源地形权重 | 复用各格四角与平地高度数据，减少相邻格重复读取；约 452ms → 141–233ms。 |
| 树木／石头外观 | 按原种子选择外观，缓存仅含选中模型的 PackedScene；200 次实例化释放，树木约 31.10ms → 6.82ms，石头约 35.28ms → 6.46ms。 |
| 悬崖接壤候选 | 脚本改名为 `随机显示自己模型.gd`，运行时缓存选中组合；245 组中移除 490 个常驻隐藏模型、980 个节点，同阶段总节点 11,136 → 10,156。未测到地形模型阶段明显提速，主要收益为减少常驻节点。 |

### 敌人染色材质释放报错

- 实际 D3D12／Forward Plus 渲染复现四种 `Parameter "material" is null` 报错，定位到带染色敌人释放时的表面材质覆盖；全部敌人三轮创建与释放共出现 84 条，不使用选中描边仍然出现相同报错。与 Godot 已记录的 [材质覆盖释放问题](https://github.com/godotengine/godot/issues/85817) 表现相同。
- 敌人染色改为模型级材质覆盖，继续复制原材质并乘配置颜色，不修改共享模型材质。相同渲染复现的空材质报错降为 0；验证全部敌人的颜色一致、选中／隐藏／释放，染色敌人真实死亡清理，以及居民转职／岗位换色释放。迷雾下居民死亡和全部敌人模型贴地渲染回归通过。
- 旧运行实例及调试器已有 128 条记录不会因修改自动消失；重新运行工程后加载新逻辑。

### 战争迷雾刷新缓存

- 39 分钟暂停现场的分析器定位迷雾刷新为主要 CPU 热点。保留原有 0.1 秒检查间隔，视野源位置／半径、昼夜倍率、树木遮挡与树冠变换均未变化时复用现有贴图；暂停期间无变化也不重算，镜头移动仍更新遮罩位置。
- 缓存建筑及已清空营地合并后的固定视野，居民移动时只重新计算动态视野并合并。建筑增减、搬迁、摧毁、箭塔视野变化、昼夜倍率及树木遮挡变化时重建缓存。移动敌人、猎物、战利品等仍检查显隐与点击状态；缓存不随刷新次数累积。
- 同场景对照原版，验证当前视野、探索记录与显示贴图逐字节一致，覆盖暂停、居民移动／死亡／隐藏、建筑变动、昼夜和树木生长／砍伐。静止刷新约 45 毫秒降至 0.05 毫秒，居民移动约 44 毫秒降至 13 毫秒；这是测试场景数据，不代表原 39 分钟游戏帧率。迷雾像素／平滑、营地清空视野、训练显隐回归及 GPU 实际迷雾渲染通过。
- 此版仍在树木遮挡变化时重建全部固定视野，尚未实现局部更新；原 39 分钟运行实例尚未加载新代码，后续需新开游戏验证整局帧率。部分无界面测试退出仍有原有 ObjectDB／资源警告。

### 资源工人待命后恢复采集

- 伐木工／采石工没有可采集资源时返回工作建筑待命，原待命逻辑只换位置、不再搜索，因此资源成熟或其他工人释放预约后仍可能持续待命。现在沿用原待命计时，在下一次待命检查时重新寻找可采集资源，无资源时继续待命，不在每帧扫描全部资源。

### 建筑攻击者优先攻击维修居民

- 转火后在警戒范围内持续追击，居民受伤停止维修并撤退不会立刻解除仇恨；维修者死亡、不可攻击或离开警戒范围后，恢复原建筑目标与原有袭扰行为。
- 专项运行验证实际伤害由建筑转向居民、受伤释放维修任务、撤退追击及原建筑目标恢复；建筑维修、裂缝索敌和怪物同盟回归通过。

### 营地守卫警戒、活动边界与回营回血

- 守卫主动攻击警戒距离内、营地活动半径内的玩家单位，居民和猎户同样会触发警戒；活动半径按营地中心的水平距离计算，沿用关卡插件营地方案中的“守卫活动半径”。
- 目标或守卫自身越界后放弃追击，沿导航返回原守卫站位，返营途中不重新索敌；回营导航独立于攻击距离，避免大攻击范围的怪物停在营地外。
- 返回站位并脱离战斗后慢慢回血，营地方案新增“守卫回营后每秒回血量”，默认 1 生命/游戏秒，0关闭；战斗与返营途中不回血，不超过生命上限，死亡守卫不复活。参数在营地生成时固定。
- 图形运行专项验证主动警戒、真实攻击与返营、边界约束及回血；营地清剿／搬运／刷新完整链路和插件保存读回回归通过。编辑器测试保存独立营地副本，共享模板保持原样。

### 箭塔被毁后的坠塔晕眩

- 正常下塔补粮、主动拆除时疏散以及尚未上塔的预留驻军不触发晕眩；落地后仍可正常受到敌人伤害。
- 图形运行测试验证两秒计时、实际暂停、禁止移动与射箭及解除后恢复攻击；箭塔入口导航和据点受击驻军防御回归通过。

### 猎户自卫撤退与居民受击避险

- 猎户发现敌人后暂停狩猎，沿导航向据点撤退，同时对射程内敌人射箭；对敌攻击力实时取弓箭手配置的一半（当前 8 → 4），对猎物仍使用猎户原有伤害 1。
- 普通居民实际受到伤害后暂停工作、逃回据点；释放公共任务、资源／农田／猎物预约及施工占位，逃跑期间不领取新任务。携带资源和猎物保留，拆除返料继续按原归属卸货。

### 资源建筑耗尽提醒

- 复现旧代码下蓝图／待施工／施工中均提前满足条件；修复后这些状态显示“缺少”且不开始移民倒计时。真实完工后显示“已满足”并开始倒计时，拆除后条件失效。

### 箭塔入口卡住修复

- 复现入口被相邻建筑遮挡时，弓箭手走到导航终点但仍检查原始入口距离，持续显示“前往军营”的问题。

- 专项测试验证两名弓箭手从旧入口目标恢复、实际绕过遮挡并进入不同塔顶站位。

### 未开工蓝图不受攻击

- 刚放下的建筑蓝图、等待材料或材料备齐但尚未施工的工地，不参与敌人建筑索敌，也不接受伤害。居民开始施工后才成为可攻击建筑。
- 已经产生施工进度的工地，工人临时离开后仍可被攻击；沿用工地血量、护甲及摧毁后的任务和材料清理。

### 迷雾建造与自动维修
