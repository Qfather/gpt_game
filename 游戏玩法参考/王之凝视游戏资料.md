# 《The King is Watching》玩法与系统运转逻辑

> 这是一份基于当前本地安装文件整理的学习笔记。重点是“系统如何互相驱动”，不是单纯的建筑或单位清单。
>
> 证据来源：`local/localization.csv`、`local/localization_aux.csv`、`parameters/Wave_templates_*.csv`、`parameters/Wave_presets_*.csv`，以及游戏内教程文本。当前文件能确认的规则写成“已确认”；只在 `data.win` 二进制逻辑中可能存在、但没有可靠文本证据的内容写成“待验证”。

## 1. 一句话理解游戏

你扮演一位国王，在一座由网格地块组成的城堡中经营生产、招募军队、研究蓝图、使用法术和国王能力；但城堡只有处于“国王凝视”范围内的建筑才会正常工作。你必须在有限的地块、资源、军队容量和时间下，发展经济并在一波波敌人和首领到来前建立防线。

核心矛盾可以写成：

```text
凝视位置/建筑布局
        ↓
有效生产与部队生成
        ↓
资源、军队、法术、士气
        ↓
抵御波次并领取奖励
        ↓
扩大凝视、解锁更高阶建筑与能力
        ↺
```

胜利不是“把所有建筑造满”，而是在每个关键波次到来前，把经济转化为足够的持续战斗力，并最终击败该区域要求的首领。城堡生命值归零则战败。

## 2. 一局游戏的状态机

### 2.1 开局

一局开始时，游戏根据关卡、国王、顾问、永久升级和挑战修正，生成：

1. 城堡网格与地块状态。
2. 初始建筑、初始资源、初始部队和基础凝视范围。
3. 当前国王的士气效果、被动能力和主动能力。
4. 时间线上的波次、商人、预言、首领等事件。

永久升级可以改变开局资源、单位上限、初始建筑/法术、顾问栏位、可出现建筑和奖励池。因此，开局并非每局固定。

### 2.2 经营阶段与战斗阶段是连续运行的

游戏不是完全分开的“建造回合”和“战斗回合”。时间线持续推进：

```text
时间流逝 → 被凝视的建筑生产/招募 → 波次事件到点
                                      ↓
                              敌军进入战场
                                      ↓
                       建筑、单位、法术实时交战
                                      ↓
                 波次结束 → 奖励/商人/预言 → 继续发展
```

教程明确说明：暂停时仍可进行大部分操作，例如建造建筑和施放法术；所以暂停主要是给玩家规划和下达指令的工具，不等于回合切换。

### 2.3 结束方式

- 城堡被摧毁：战败。
- 按条件完成区域目标并击败最终首领：胜利。
- 部分模式允许提前结束一局并按当前进度获得结算，但仍需按照界面提示达到可结束条件。
- 胜利/结算会推进城镇便士、擢升水晶、解锁关卡、无尽/自由模式、排行榜记录等长期内容。

## 3. 地块、凝视与布局

### 3.1 凝视是全局生产开关

教程的明确规则是：只有在国王凝视范围内的建筑才能正常运转。凝视范围可以移动和旋转，升级凝视后可以监督更多建筑。

因此建筑有两种状态：

- 在凝视内：可以生产资源、招募单位、生成法术或执行攻击/治疗等工作。
- 不在凝视内：通常停止工作；少数建筑或升级具有“无需凝视”的例外。

这使得“把所有建筑造在一起”并不总是最优：密集布局容易被一次凝视覆盖，但会产生地块拥挤、资源链距离和防御覆盖问题。

### 3.2 地块状态

当前文本确认的地块状态包括：

- 普通地块。
- 肥沃地块：提高地块上增益效果的生产效率。
- 贫瘠地块：削弱地块上增益效果的生产效率。
- 资源/建筑占用地块。
- 岩石、沼泽、木屑等障碍地块：清除前不能建造。
- 贵族占用地块：需要永久升级树中的清理项目才能移除。
- 地块印记：普通、史诗、传说、诅咒等品质；印记会改变地块生产。
- 区域特殊占用：例如沙漠化、水淹、触手侵袭。

### 3.3 建造、移动和拆除

- 建筑建造会消耗资源；重复建造同一建筑时，费用会按界面提示提高。
- 建筑可以移动，但移动后会在一段时间内降低生产速度；水井是教程点名的例外。
- 拆除建筑不会返还建造资源。
- 生产型建筑通常有有限的生产次数/资源储量。资源耗尽后，建筑会被摧毁，需要重新建造或替换。
- 建筑的邻接关系很重要：某些设施只有放在指定建筑旁边才会工作或生成特殊单位。

## 4. 资源经济：从基础资源到军队

### 4.1 资源分类

本地化表中确认的主要资源如下：

| 资源 | 主要用途/来源 |
|---|---|
| 水 | 最基础的生产投入，用来启动其他生产链；水井生产水。 |
| 木材 | 基础建筑材料；树木、锯木厂等生产。 |
| 黏土 | 建筑/加工材料；黏土矿生产。 |
| 矿石 | 工业基础；铁矿生产，之后可在熔炉加工成金属。 |
| 金币 | 市场出售货物获得；可在商人处购买商品。 |
| 水晶 | 魔法能量；水晶矿、国王被动、击杀类神器等来源。 |
| 小麦 | 食物及若干加工链投入；麦田生产。 |
| 葡萄 | 葡萄园生产；酿成葡萄酒。 |
| 肉 | 动物/渔业相关生产；部分单位和建筑需要。 |
| 面粉 | 小麦经磨坊加工；龙类/骷髅相关升级可能使用。 |
| 金属 | 矿石经熔炉加工；高级工业和部分军队需要。 |
| 燃料 | 工业能源；燃料泵生产，炮类建筑会消耗。 |
| 家具 | 木材加工产物；后期建筑可出售换城镇便士。 |
| 葡萄酒 | 葡萄加工产物；提供士气，并在部队战斗中持续消耗。 |
| 遗物 | 墓园区域专用货币；废墟挖掘和墓园商人使用。 |
| 地狱符文 | 火山区域专用资源；用于火山交易/解锁地狱体系。 |
| 城镇便士 | 长期/城镇系统货币；来源包括波次和首领，购买升级或特殊商品。 |
| 擢升水晶 | 长期成长货币，用于擢升/永久升级体系。 |

“金币”和“城镇便士”是两个不同层级的货币：金币服务于当前一局的商人交易，城镇便士服务于局外成长或特殊商店。

### 4.2 生产链的通用逻辑

建筑的生产可抽象为：

```text
满足凝视/激活条件
        +
拥有输入资源
        +
建筑仍有生产次数或储量
        ↓
经过生产周期
        ↓
扣除输入 → 产出资源/单位/法术/攻击效果
```

常见链条：

```text
水井 → 水 → 麦田 → 小麦 → 磨坊 → 面粉
树/锯木厂 → 木材 → 木工/家具体系
黏土矿 → 黏土
铁矿 → 矿石 → 熔炉 → 金属
金矿 → 金币
水晶矿 → 水晶
葡萄园 → 葡萄 → 酒厂 → 葡萄酒
燃料泵 → 燃料 → 炮/工业攻击建筑
```

进阶生产建筑往往一次涉及多个资源，但生产速度更慢；因此“多资源但慢”和“单资源但稳定”是两种不同的经济取向。

### 4.3 市场

市场是把库存资源转换成金币的出口：

1. 选择市场。
2. 在管理界面选定可出售资源。
3. 市场在有效工作时持续交易。
4. 资源减少，金币增加。

部分资源不能在市场出售；市场还可能通过升级获得士气、折扣或额外收益。市场是解决“生产链有余量但缺金币”的关键建筑。

### 4.4 生产效率的叠加来源

生产速度可能受到以下因素影响：

- 凝视是否覆盖。
- 地块肥沃/贫瘠和地块印记。
- 建筑自身升级。
- 国王被动/主动能力。
- 顾问。
- 神器。
- 事件、庆典和关卡修正。
- 建筑移动后的暂时惩罚。

具体叠加顺序和是否相加/相乘，当前文本无法确认；学习时应以当前建筑面板显示值和实际生产周期为准。

## 5. 建筑系统

建筑在功能上分为四大类，界面也按此分类：

### 5.1 生产类

生产基础资源或加工品：水井、麦田、树、黏土矿、铁矿、金矿、水晶矿、葡萄园、磨坊、熔炉、酒厂、锯木厂、燃料泵、家具类建筑等。

学习重点：先建立稳定输入，再投资加工链。加工品通常更适合转化为金币、士气或高阶兵种，而不是盲目追求单项资源数量。

### 5.2 部队类

部队建筑持续招募单位，例如农民、民兵、剑士、弩手、长弓手、法师、骑士、亡灵、恶魔或区域专属单位。它们通常有：

- 生产速度。
- 单建筑容量。
- 招募成本。
- 生成位置：战场、营地，或先填满战场再进入营地。
- 部队等级/兵种升级。
- 建筑专属升级。

### 5.3 防御/攻击类

炮、弩车、投石车、特斯拉、火焰/毒素建筑、墙体维修等，不一定生产传统资源，而是把资源转换为直接战场效果。比如炮消耗燃料生产炮弹，气球需要燃料投弹，墙体维修恢复城堡防御。

### 5.4 杂项/辅助类

市场、研究台、魔法学院/大学、酒馆、竞技场、医院、国王雕像、地块附魔器、建筑升级相关设施等，负责经济转换、法术、士气、治疗、研究或全局增益。

### 5.5 建筑升级

建筑升级通常不是简单“加等级”，而是改变一项局部规则，例如：

- 提高产量、生产速度或容量。
- 降低招募/生产成本。
- 让弩手的特定攻击触发双倍伤害或眩晕。
- 让投石车获得眩晕几率。
- 让建筑在无凝视时工作。
- 让死亡、击杀、攻击或生产事件返还资源。
- 给单位增加生命、伤害、攻击范围、减速、毒素、燃烧或治疗。

所以选择升级时，应先看自己的瓶颈是“没有资源”“资源来不及加工”“单位不够多”“单位不够硬”还是“建筑覆盖不全”。

## 6. 军队与战斗

### 6.1 两个容量概念

- 单建筑容量：一座营地最多容纳/生产多少该类单位。
- 全局单位上限：战场与可用军队的总上限；达到后不能继续招募新的有效战斗单位。

营地中的单位不会参与当前战斗，是后备军。管理界面可以：

- 把战场单位送进营地。
- 从营地补充到战场。
- 快速补充全部可用兵力。
- 解散单位以释放单位上限。

这意味着“单位上限”是生产系统的硬闸门，不能只堆招募建筑而不升级上限。

### 6.2 单位生成位置

界面确认至少有三种模式：

1. 生成到战场。
2. 生成到营地。
3. 先生成到战场，达到最大容量后继续进入营地。

不同模式对应不同目的：战斗前快速补兵、平时储备精英单位、或者避免新单位因上限暂时无法生产。

### 6.3 单位特性与协同

绝大多数单位有自己的特性。特性可能影响：

- 伤害、生命、攻击速度、移动速度。
- 远程攻击、范围攻击、减速、毒、燃烧、眩晕。
- 生产/死亡/击杀时的资源收益。
- 与特定单位、建筑、国王、士气或地形的协同。

教程明确建议通过建筑或营地单位提示查看特性；因此不能只按面板伤害判断兵种价值。

### 6.4 酒与士气

葡萄酒为部队提供士气，并在部队战斗时持续消耗。库存葡萄酒既是增益来源也是持续成本：

```text
葡萄园 → 葡萄 → 酒厂 → 葡萄酒
                             ↓
                 战斗时持续消耗并提供士气
```

士气来源包括基础值、葡萄酒、竞技场、黑绵羊、神器、不同单位种类数量和国王任务等。不同国王把士气转化为不同收益，例如单位伤害、建筑生产、法术伤害或亡灵伤害。

## 7. 城堡生命值与防守

敌军进入战场后会攻击己方单位和城堡。城堡生命值是整局最重要的失败资源之一：

- 墙体维修建筑可以恢复城堡墙体。
- 医院主要治疗受伤部队，不等于修城堡。
- 某些神器在单位死亡、施法、生产建筑耗尽或城堡濒危时治疗城堡。
- 部分国王能力会在城堡生命值降低到阈值后触发额外援军。
- 血液、暗能等区域/首领资源会在首领到达时增加其生命值，属于玩家必须提前控制的“敌方增益资源”。

防守不是单纯造墙：远程/范围攻击负责清群，近战单位承伤，治疗/控制单位延长部队存活，法术处理关键目标，国王能力在危机时改变战局。

## 8. 波次、时间线、预言与首领

### 8.1 时间线

时间线会展示敌方部队波次、首领波次、预言和商人事件。参数表中的“周”是事件节点；不同区域的节点略有差异。

### 8.2 普通区域的波次模板

村庄、墓园、火山和流沙使用相近的节奏：前期约在第 12、22、32、42 周出现关键节点；中段约第 52/57、63/65 周；后段约第 77、88、99、113/114、119 周。

- `prophecy`：预言节点。
- `shop`：商人节点。
- 普通节点从对应难度范围抽取波次预设。
- 每个波次预设由一个或多个敌方单位及数量组成，并有总力量值。

教程区域使用另一套节奏：第 12、24、38、46、58、66、76、82、89、94、102 周，并在后段标记商人、预言和首领旗帜。

黑暗领域的节奏是第 10、20、32、44、56、67、79、94、108、122、134 周；它更早进入特殊区域机制。

### 8.3 预言

预言是风险—收益选择：玩家可以在接下来若干波次中选择要面对的敌人或难度。规则文本明确说明：敌人越强，奖励越好，但选择过强的波次可能摧毁城堡。

实战流程：

1. 预言节点出现。
2. 查看可选卡牌及可能奖励。
3. 比较敌方力量、敌人类型、自己当前经济和防守能力。
4. 选择高收益高风险，或选择可稳定处理的方案。

### 8.4 敌方波次预设

波次预设不是单个随机敌人，而是“敌人组合 + 数量 + 预估总力量”。例如村庄早期有哥布林盗贼、弩手、破墙者和剑士；后期加入巨人、萨满等。不同区域替换为僵尸、黏土怪、熔岩/恶魔单位、沙漠单位或触手单位。

参数表中还能看到“简单/中等/困难波次”的编号范围，因此预言或时间线首先决定难度区间，然后从该区间抽取具体预设。精确随机权重未在文本参数中公开。

## 9. 奖励、商人、研究与蓝图

### 9.1 波次奖励

击败波次后领取奖励。奖励类别包括：

- 资源。
- 基础建筑。
- 基础/进阶/高级生产建筑。
- 新兵/老兵/精英营地。
- 杂项设施。
- 建筑升级。
- 普通法术/传说法术。
- 神器/传说神器。
- 部队兵种训练。
- 城堡修复。
- 便士。
- 预言、遭遇和特殊区域奖励。

当某一类奖励已没有可提供内容时，界面可能把它替换为资源或其他奖励；永久升级还可以增加重掷、放逐建筑或扩展研究选项。

### 9.2 商人

商人出售建筑、法术、资源、神器等。金币主要来自波次奖励和市场。商人商品可能有折扣、锁定商品、重掷和特殊商品；局外升级可解锁更高级的商店内容。

### 9.3 研究台

研究台提供建筑/类别选择，研究完成后获得对应蓝图或建筑选项。局外升级可以：

- 增加研究台数量。
- 增加研究台选项。
- 解锁王国基础设施、新兵营地、进阶/高级生产、精英营地等类别。
- 解锁更多建筑包。

### 9.4 蓝图

蓝图是“建筑或能力的选择权”，不是立即等同于建筑。国王雷欧的体系还可以把选中的蓝图献祭，换成永久士气和自选资源；后续皇家任务会提高该能力收益。

## 10. 法术系统

法术由奖励、魔法学院/大学、国王能力、神器和特殊建筑获得。法术有栏位限制；获得法术不代表可以无限施放，实际使用要受库存、冷却、栏位或资源条件限制。

基本流程：

```text
法术建筑/奖励生成法术
        ↓
法术进入栏位
        ↓
拖入战场并选择目标区域
        ↓
立即产生伤害、控制、治疗、召唤或经济效果
```

法术通常分为：

- 直接伤害/范围伤害。
- 控制、减速、眩晕、点燃、毒素。
- 治疗、复活、增益。
- 召唤临时单位。
- 资源、生产、凝视或建筑辅助。

法术伤害受国王、神器、建筑升级、永久升级、单位协同和区域修正影响。黑暗领域中，凝视被俘获触手可以削弱其他触手的护盾；教程明确提示直接攻击护盾中的触手可能无效，因此需要先处理区域机制。

## 11. 国王系统

国王不是纯外观选择，而是整局的规则改写器。当前本地化表确认的国王包括：

| 国王 | 体系重点 |
|---|---|
| 贤者雷欧 | 蓝图献祭、额外草稿；士气同时提高单位伤害和建筑生产。 |
| 萨拉丁 | 多样性；按军队中不同单位种类提供士气，主动能力获得随机蓝图/单位。 |
| 秘法之主 | 魔法；被动生成水晶，主动获得普通/强力法术，士气提高法术伤害。 |
| 雷奥尼德 | 面具/坚韧；全建筑生产、单位生命或双倍生命生成等能力。 |
| 阿鲁卡多 | 亡灵；活着的单位死亡后有机会转为亡灵，主动复活尸体或升级亡灵。 |
| 布雷尼乌斯 | 坦克/高生命；生命值转化为伤害，达到士气阈值可获得奖励，并有治疗/嘲讽能力。 |
| 唐太宗、克利奥帕特拉、薛西斯等 | 当前文件中存在解锁条目和部分专属资源/体系；具体内容以是否已解锁及当前版本界面为准。 |

国王能力分为：

- 被动能力：一直改变士气、生产、伤害、单位生成或资源规则。
- 主动能力：需要冷却，通常在战斗中施放，召唤、治疗、强化、控制或获得资源。
- 皇家任务：达到击杀、士气、单位数量、施法次数等条件后获得额外能力。

国王的凝视范围、士气换算和能力升级路径各自不同，不能把一个国王的开局节奏直接套到另一个国王上。

## 12. 顾问、神器和部队训练

### 12.1 顾问

顾问由城镇升级解锁，通常需要议会。顾问提供局外或开局被动，例如：

- 开局便士、资源、单位或神器。
- 建筑生产速度和建造费用。
- 法术生成速度。
- 部队成本、生产速度、单位上限。
- 城堡最大生命值。
- 预览更多首领。
- 开局庆典、临时召唤、复活概率。

顾问栏位有限，所以顾问配置本质上是“本局战略方向”的选择。

### 12.2 神器

神器是跨系统的被动修正，典型效果包括：

- 资源生产加速。
- 全体部队伤害/生命/上限/攻击速度。
- 法术伤害、法术重复施放、施法治疗城堡。
- 击杀敌人获得木材、矿石、水晶、葡萄或金币。
- 单位死亡触发复仇、爆炸、召唤或复活。
- 生产建筑耗尽时获得治疗或临时单位。
- 每波开局获得资源、临时弓手、鹅骑士等。
- 地块变为生产地块或放置传奇印记。

神器通常要看触发频率：击杀触发适合高频清群，生产耗尽触发适合短局或有限储量建筑，按波触发适合首领前囤积。

### 12.3 部队训练

部队训练奖励会强化某个兵种类别或单位特性，例如容量、伤害、生命、攻击范围、眩晕、毒、燃烧、成本、生产速度等。它与具体建筑升级不同：前者更偏向兵种全局训练，后者更偏向建筑局部强化。

## 13. 区域专属系统

### 13.1 教程/村庄

村庄是基础经济和哥布林防守教学区。学习顺序通常是：水井 → 小麦 → 农民 → 市场 → 弩手/专业军队 → 凝视升级 → 营地管理 → 预言和奖励。

### 13.2 墓园

墓园的核心是废墟、挖掘者和遗物：

- 遗物是区域货币。
- 废墟中可挖出特殊遗物/神器。
- 墓园商人用遗物出售稀有商品。
- 墓园商人有时出售复活的士兵。
- 废墟斥候/挖掘者需要被招募并派去搜寻宝藏。

### 13.3 火山

火山围绕地狱符文和献祭祭坛运转：

- 通过采集/献祭获得地狱符文。
- 祭坛可以献上资源，某些情况下也能献上士兵。
- 累积足够符文后，从火山交易中获得回报并解锁地狱部队/建筑。
- 火山区域的敌人和建筑形成独立的地狱体系。

### 13.4 流沙之地

流沙强调可选挑战和自定义对局：

- 玩家可以自行选择即将面对的危险。
- 挑战越困难，分数和解锁收益越高。
- 挑战修正可能提高敌方伤害、生命或生成数量。
- 沙漠地形、资源和敌人组合会改变常规经济布局。

### 13.5 黑暗领域

黑暗领域的核心是触手和护盾：

- 触手会主动袭击外来者。
- 触手受到某种护盾保护，直接攻击可能无效。
- 凝视被俘获的触手可以削弱其他触手的护盾。
- 等待越久，出现的触手越多，因此“拖时间发育”不是无成本策略。
- 区域中有暗能资源；首领抵达后会吸收暗能并提高生命值。

## 14. 局外成长与擢升

局外系统把本局所得转化为长期解锁。当前文本确认的方向包括：

- 解锁国王。
- 解锁顾问及顾问栏位。
- 增加初始单位上限。
- 永久提高部队伤害和生命。
- 永久提高法术伤害。
- 增加起始葡萄酒、随机法术、起始建筑和资源。
- 增加研究台和研究选项。
- 解锁新建筑包、新法术和特殊商店商品。
- 增加免费重掷、神器重掷和奖励放逐机会。
- 移除贵族占用地块。
- 解锁挑战、图鉴、升级和更多关卡。

局外升级的战略价值不是简单的“全部点满”，而是决定之后每局的起始方向：经济型、法术型、军队型、神器型或特殊区域型。

## 15. 挑战/擢升修正

擢升系统通过给一局施加负面条件来提高威胁等级和结算奖励。当前文件列出的例子包括：

- 建筑更贵、不能拆除、建造会损失城堡生命。
- 初始资源负债、初始城堡缺血、减少水井。
- 降低部队生命/伤害/生产速度或营地容量。
- 减少法术栏位。
- 葡萄酒提供更少士气、部队喝酒消耗变化。
- 敌人死亡复活、死亡爆炸、每波落雷、敌方伤害/生命/数量提高。
- 鸟群消耗过量小麦。
- 地块被水淹、沙漠化、触手占据。
- 使用国王能力触发牺牲或雷击。
- 首领登场时召回此前首领。

挑战的正确玩法是先确认它改变了哪个瓶颈，再调整开局：例如“部队生产减速”要求提前扩大生产能力；“不能拆除”要求更谨慎规划；“敌人死亡爆炸”要求避免低生命单位密集承伤。

## 16. 推荐的学习顺序

### 第一步：只练经济闭环

在教程/村庄中先做到：水井稳定供水、麦田稳定产粮、能建农民、能建市场并出售小麦。此时不要急着追求高级建筑。

### 第二步：练凝视和布局

刻意移动凝视，观察哪些建筑停工；再用尽可能小的凝视范围覆盖生产链。把生产链和军队建筑放在容易共同覆盖的位置。

### 第三步：练单位上限与营地

让战场单位接近上限后，学会把弱单位送进营地、把精英单位留在战场，并在波次前快速补充。

### 第四步：练市场和士气

用市场换金币，用葡萄酒维持士气，比较“卖葡萄/卖酒/保留资源”的机会成本。

### 第五步：练预言风险

每次预言先看敌方类型而不是只看总力量：破墙者、远程、控制、首领增益和区域特殊敌人的威胁完全不同。

### 第六步：围绕国王构筑体系

先决定本局是蓝图、法术、多样单位、亡灵、坦克或生产方向，再选择对应建筑、神器、顾问和升级，不要每类奖励都平均拿。

## 17. 实战决策检查表

每个关键波次前问自己：

1. 下一个波次是什么时间？是普通波、商人、预言还是首领？
2. 当前凝视能覆盖哪些关键建筑？战斗开始时会不会因为移动凝视导致经济停摆？
3. 城堡生命值、墙体修复能力和治疗资源是否足够？
4. 单位上限是否已满？战场与营地分别有多少单位？
5. 葡萄酒库存能支撑多久？士气收益是否值得继续消耗？
6. 当前真正的瓶颈是输入资源、加工速度、金币、单位容量、单位质量还是法术？
7. 下一项奖励应该补短板，还是放大已有协同？
8. 建筑资源是否即将耗尽？是否要提前准备替代建筑？
9. 预言的额外收益，是否值得承担敌人类型带来的特殊风险？
10. 国王主动能力和法术应该现在用，还是留给首领？

## 18. 当前证据的边界

以下内容在本地文本中只能确认“存在该系统或效果”，不能从 `localization.csv` 单独确认完整内部公式：

- 生产周期、攻击间隔、伤害计算顺序和护甲/减伤公式。
- 波次预设的随机权重、重复抽取规则和预言具体抽样算法。
- 建筑加速效果的相加/相乘顺序。
- 单位 AI 的寻路、仇恨、目标选择和碰撞规则。
- 首领完整登场顺序、每个首领的精确技能数值。
- 建筑升级的全部数值参数和每个区域的隐藏掉落表。
- `data.win` 中未暴露为本地化文本的内部状态转换。

因此，本稿适合学习“系统关系和决策逻辑”，不应替代游戏内当前版本面板的精确数值。若要继续做精确攻略，应通过实际游玩记录生产周期、资源消耗、单位伤害和波次结果，再与本稿的系统框架对应。
