# 风格化天空与昼夜插件（第一版）

## 2026-10-01 更新

- 增加“启用光束效果”开关，使用 Forward+ 体积散射与太阳／月亮光源，模型云和小云团通过只投影网格参与遮挡。关闭开关后停止体积光并关闭新增云影和月光阴影。
- 插件默认开启光束，当前游戏主场景明确关闭，可按场景检查器重新开启。
- 游戏战争迷雾已订阅 `night_visibility_changed`：白天倍率为 1，夜晚使用组件设置。插件继续只提供信号，具体迷雾计算由游戏实现。
- `addons/lens_effects` 是单独的上游光束／光晕演示，已在本机 D3D12／Forward+ 验证，尚未接入本插件或主场景。

Godot 4.7 插件，独立于游戏关卡。它提供一个可复用的 `StylizedDayNight` 节点，运行时创建自己的 `WorldEnvironment` 和太阳方向光，并按昼夜进度插值天空、地平线、地面颜色及光照。天空着色器绘制太阳、月亮、渐隐渐显的星星和程序化移动云层。

## 试运行

1. 单独打开 `addons/stylized_day_night/demo/demo.tscn` 并运行（F6），无需启用插件即可看演示。
2. 演示循环设置为 120 秒一昼夜；组件默认 600 秒一昼夜，可在检查器修改。
3. 演示中按住鼠标右键拖动旋转镜头，滚动滚轮缩放；右侧 HUD 可调整当前时刻、昼夜周期、夜间视野，以及程序化云、两种 `modle` 目录下的 Synty 环形云，或“小云团环”模式。小云团环由三种基础球体组合随机实例组成，可复制/删除环，并分别调节每环半径、高度和 Y 旋转；云环配置自动保存。大小与速度滑杆对云层生效；模型云高度滑杆控制整体上下偏移（-10 至 +10 米）。Synty 模型云保留 GLB 自带缩放，再按“云层大小÷5”调整，并围绕网格包围盒中心缩放；速度滑杆控制 mesh 绕 Y 轴匀速旋转。模型云使用普通透明材质，颜色随昼夜从暗蓝灰过渡到浅白。
4. HUD 参数变动后自动保存到 `user://stylized_day_night_demo.cfg`，关闭场景时也会保存；下次运行演示自动恢复。

演示 HUD 是运行时界面，不依赖编辑器插件；天空编辑器插件当前保持禁用。游戏主场景 `Scene/main.tscn` 已实例化 `StylizedDayNight`，由它创建昼夜天空环境和太阳方向光，原主场景环境及方向光已移除，避免重复生效。该节点的中文昼夜、云层和远景雾参数可在主场景检查器中调整；脚本内部属性名保持不变，以兼容演示场景和已有配置。远景雾在插件中默认关闭，在主场景中开启；雾色随昼夜地平线颜色变化。

## 参数和接口

- `cycle_length_seconds`：完整 24 小时周期所需现实秒数。
- `start_hour`：启动时的游戏时刻，范围 0–24。
- `cycle_paused`：暂停插件自身昼夜计时。
- `night_visibility_multiplier`：夜晚对外提供的视野倍率，默认 0.8；插件只发出信号，不直接控制单位或战争迷雾。
- `light_shafts_enabled`：检查器中的“启用光束效果”，默认开启。白天跟随太阳，夜晚跟随月亮，颜色和强度沿用现有光源；使用引擎体积散射和阴影；关闭后停止体积光，并恢复月光和云模型原有的无阴影状态。
- `clouds_enabled`、`cloud_style`、`cloud_density`、`cloud_scale`、`cloud_speed`、`cloud_opacity`、`mesh_cloud_altitude`、`cloud_rings`：云层开关与样式、云团密度/尺度、共同速度和透明度、模型云高度，以及可调的环形云团配置。
- `distant_fog_enabled`、`distant_fog_begin`、`distant_fog_end`：远景距离雾开关及起止距离。打开检查器中的“自定义雾颜色”后，“雾颜色”代替随昼夜变化的地平线颜色。
- `set_game_hour(hour)`：立即设置游戏时刻并重置本周期计时。
- `time_changed(hour, day_progress)`：时刻或进度更新信号。
- `night_visibility_changed(multiplier)`：昼夜视野倍率更新信号，白天为 1，夜晚为设置值。

## 当前范围

太阳和月亮的光束使用 Godot Forward+ 体积散射，低密度介质与独立的体积光能量配合，让主场景俯视镜头也能看到树木遮挡形成的光束。开启时月光投影生效，模型云和小云团添加只投影、不显示的同形状网格；关闭后这些新增投影也关闭。原有云层透明材质、昼夜周期、表面光照能量、远景距离雾和战争迷雾视野保持原规则。程序化天空云没有三维几何，不参与体积光遮挡。`addons/lens_effects` 保留为独立原版演示，天空组件不再依赖它。

包含风格化昼夜天空、太阳/月亮圆盘、夜间星星、程序化云、两种 Synty 环形云与基础球体组合的小云团环、太阳方向光、独立演示场景与夜间视野倍率接口。昼夜天空已接入游戏主场景；天气、游戏 HUD/计时器及战争迷雾视野倍率尚未接入。演示场景使用云层脚本默认值，避免把导出选项覆盖为 `null` 后导致云层关闭。Synty 模型云使用插件目录中的两个 GLB，保留模型自带缩放并通过普通透明材质着色；Unity Shader Graph 尚未移植。

演示 HUD 仅用于独立测试场景的实时调参，不会自动出现在游戏关卡中；参数存档也是演示场景自己的 `user://` 配置。

## 初步验证

已使用 Godot 4.7.2 / Forward+ / D3D12，在主场景原镜头下截图比较白天与夜晚的体积光开关，检查开关关闭时月光和云新增投影关闭；主场景战争迷雾可见图、远景雾参数、昼夜表面光照能量和视野倍率保持一致。主场景退出时的 RID 泄漏和 HealthLabel 重名告警，在使用改动前的天空脚本时也出现，本次未改动相关逻辑。

需在编辑器运行独立演示场景，确认程序化云及两种环形云可切换显示，并观察太阳/月亮/星星和云层移动及色彩观感。
