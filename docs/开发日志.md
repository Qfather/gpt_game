## 2026-10-08：瞭望塔警报、居民回家避险与性能诊断

- 新增战略建筑瞭望塔：2×2、木材20、施工15秒、血量300，安排一名居民从正面沿梯子登上平台。实际登塔后才启用水平20米警戒，选中显示圆形范围；面板提供安排与撤岗，居民在塔上保持可见，进食或休息离岗暂停警戒，回岗恢复。
- 普通居民不再自行遍历敌人组。统一警报每0.2真实秒检查所有有效塔；发现敌人后，未受完整城墙保护的非战斗居民固定回自己的住所，无家则回据点，保持岗位并在解除警报后复工。没有有效警报时仅受击触发避险；值班居民留塔，战斗单位保留战斗行为。警报期间已回屋者等待解除，避免反复进出。
- 城墙保护缓存按完工防线闭环计算，覆盖城门轴向、缺口、高低差与对角漏缝；敌人进入围合区域后，该区域暂不豁免避险。城门当前没有开关、仍保留通道，本轮没有将实体挡敌标记为完成。
- 瞭望塔有画面测试与截图检查通过：真实登塔、中文详情、选中20米范围、进食回岗、撤岗、取消工作、搬迁及塔被毁撤离。城墙闭环测试，以及建筑正面进入、农舍避难、住宅正面避险、训练进门中断、狩猎需求、防线系统、迷雾对象生命周期和显隐缓存回归通过。施工与训练返回测试按新规则改为回自己的住宅；平面导航测试指定据点正面可达待命点，避免未烘焙碰撞体造成随机路线失效。
- 迷雾优化保留逐像素等价：缓存像素世界位置、方向与静止遮挡，完全亮区域跳过无效遍历；33居民/15敌人3倍速持续战斗约45→67 FPS。66居民/30敌人旧避险布局仍约7 FPS，拆分发现居民搜敌约33ms、双方避让约18ms、敌人选敌约9ms；扩大测试避难容量后约27 FPS。详细条件与重叠计时说明见[性能报告](迷雾与袭扰压力测试_2026-10-08.md)。
- 上述压力数字采自修改警报规则之前；本轮移除普通居民重复搜敌并调整回屋规则，没有据此承诺新规则的大规模帧率，也未取消单位避让。完整关卡及用户第19分钟现场仍需复测。默认瞭望塔为可替换木结构基本体，详细规则见[瞭望塔警戒与居民避险](瞭望塔警戒与居民避险.md)。
- 按用户要求更新 README 与今日日志并上传本次对话的玩法修复、瞭望塔与性能测试代码；排除本地测试缓存、截图及原有据点建模删除、木墙参数、Boss外观和美术参考图改动。

## 2026-10-08：建筑正面进入、城墙清障与职业修复

- 建筑进入判定从单一门口点放宽为有门模型所在的正面；移民、普通工作与避险复用可达正面入口，保留排队进出。城墙工人在工地外侧站位施工，预览取消墙体朝向箭头，并以黄/红/绿区分材料不足、不能建造和可建造。

## 2026-10-08：避难到点、受击回弹、同类多选与木制升级

- 农舍避难增加到点容差：导航目标须位于建筑正面，居民在目标附近且距正面范围不超过 0.35 米时允许进门，避免导航已停止而入门判定仍拒绝。正面以外的侧面、背面仍不能进门。
- 普通攻击的受击反馈仅移动 VisualRoot：向攻击反方向偏移 0.15 米后回弹，连续受击重置到原始位置，不累积推移。角色碰撞体、导航位置不随受击变化。
- 双击建筑或居民多选可见的同类对象；木墙、木城门、木塔楼可批量升级为石制。升级费用逐种材料取石制成本减木制成本的正差，不退负差；原建筑保留至完工，取消升级保留原建筑和占地，塔楼升级保留驻军与军粮。石墙、石城门、石塔楼从直接建造菜单隐藏。
- 迷雾缓存对象的网格与碰撞节点列表，增删节点时失效，减少刷新中重复扫描节点树；保留现有显隐、拾取与视野判定。
- 有画面验证：升级菜单的数量和合计差价显示正常；同类多选、取消升级、石制替换、驻军与军粮保留测试通过；建筑实际点击与范围显示、真实居民死亡和火把迷雾渲染测试通过。
- 无界面回归：农舍真实避难行走及入口边缘容差、受击模型回弹与实体位置不变、三种木制防线的实际差价交料与外侧开工、暂停选择、迷雾建造、迷雾像素等价与视野生命周期测试通过。双人施工测试使用复制配置将施工上限设为 2，保留当前木墙配置的单人施工参数。建筑点击和死亡渲染测试需要有画面的进程，不能使用无界面运行结果验收。
- 3 倍速性能对照使用固定种子 418、11 名居民、农场和 5 个不造成伤害的敌人，事件与营地生成停用；每阶段记录 180 帧。未缓存对象节点时，有敌人阶段 P50/P95/最大帧时为 13.236/30.340/62.972 毫秒，缓存后为 13.154/23.671/47.383 毫秒；迷雾手动刷新五次的平均耗时从 14.890 降至 10.165 毫秒。
- 性能验证边界：这里只把遭遇计时设为 19 分钟，没有连续游玩至该时间，也没有用户当局建筑和任务布局；未复现持续 7 FPS，不能据此认定原场景掉帧已解决。性能探针支持 `-- --triple`，另加 `--uncached` 可对照缓存前扫描方式。日志和截图位于本地 `.godot`，未提交或上传 Git。
