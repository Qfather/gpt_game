# 开发日志

本文件按日期记录改动、验证与剩余问题。当前使用说明见 [README](../README.md)，后续方向见 [ROADMAP](ROADMAP.md)。

## 2026-10-07：建筑配置保存范围修复

- 建筑编辑器原先每次保存通用配置都会重新写入功能场景，导致打开的 `base.tscn` 即使内容未变，也可能提示磁盘文件较新。
- 通用属性、外观引用及仓储配置只保存 BuildingData；建筑专属参数发生变化时标记场景待保存，场景写入成功后清除标记，重新载入场景也清除标记。
- 新增 `Tests/building_scene_save_scope_test.gd`，测试使用 `.godot` 下的隔离据点场景及配置：修复前复现通用属性保存导致场景时间改变，修复后验证场景时间与内容保持、专属人口容量自动保存读回、切换建筑前补保存不重复写场景。
- 保存范围测试与既有 `plugin_autosave_test.gd` 均在新启动的无界面编辑器进程通过，退出码为 0；退出仍有既有 RID／资源释放告警，既有测试还出现 Dummy 渲染纹理告警，不作为无告警验收。
- 当前用户编辑器里的磁盘冲突弹窗未重新做交互验收；旧插件实例需重新加载后再确认，不修改用户正在编辑的场景或配置。
