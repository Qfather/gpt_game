# 建筑蓝图与公共训练

当前实现：2026-10-09。旧的 [T0～T3方案](t0-t3建筑蓝图解锁计划.md) 是设计记录，以本文和当前代码为准。

## 开局与蓝图

| 等级 | 建筑 | 使用方式 |
| --- | --- | --- |
| T0 | 伐木场、采石场、农舍、民兵营、住宅 | 开局可建 |
| T1 | 猎人小屋、军营、箭塔 | 获得各自蓝图后直接建造 |
| T1 | 剑士营、弓箭手营 | 获得各自蓝图后，从民兵营选择分支升级 |

据点保留开局场景，道路、火把和木制防线沿用原规则。石制防线仍由木制补材料差价升级，不出现在普通建造菜单。

等级大于零自动需要本局蓝图，没有另外的开关允许绕过。蓝图不是一次性建造券，不赠送免费建筑；选择后本局持续有效，可重复建造或升级，每次正常支付费用。重新开始游戏重置蓝图。

蓝图池按 `blueprint_pool` 筛选：排除已获得的蓝图和没有有效功能场景的定义；存在前置关联时，要求前置建筑的蓝图权限已满足。T0默认满足前置条件，T2/T3分支需要先获得对应前置蓝图，**不要求地图上已建成前置建筑才进入池**。实际升级仍须选中对应的前置建筑。

## 三选一测试

1. 运行游戏，展开左上角调试HUD。
2. 选择随机池，默认 `standard`。
3. 点击“测试：抽取建筑蓝图（三选一）”，选择一张卡。
4. 直接建造类立即加入底部菜单；升级类在民兵营详情中启用相应分支。

每次最多三张，选项互不重复。不足三张显示实际剩余数量，池为空给出提示。关闭窗口再打开保留同一组选项，不刷新；选择后才清除本组选项。窗口打开时暂停模拟，选择或关闭后恢复原来的暂停状态。

**正式关卡的奖励时机、掉率、存档和局外解锁尚未接入**；目前通过调试按钮测试真实解锁流程。开发入口没有额外发材料，资源不足仍须采集。

## 建筑插件配置

Godot底部“建筑”面板继续使用同一套 `data/buildings/*.tres`。

- 选中已有建筑，点击“复制当前模板，新建建筑”，填写唯一英文ID和名称；复制产生新资源，不覆盖模板。功能场景提供已有建筑行为，外观模型可另选。
- “通用建筑属性”设置分类、T等级、蓝图随机池ID、允许直接建造、升级材料和升级时间，以及已有建造参数。
- “等级与前置关联”从前一级建筑选择父级，并查看关联树。选择父级时默认关闭直接建造；确需直接建造的定义可在通用属性里设置。
- 开启直接建造时，前置关联只用于蓝图池，不产生原地升级按钮，也不限制父子占地相同。本版原地分支升级用于公共训练营；其他生产或驻军建筑的升级迁移尚未扩展，插件会拒绝将其配置为原地升级，避免丢失库存、工人或驻军。
- “公共训练配方”设置总槽位、添加／删除训练项，从已有军事单位中选择兵种，配置材料、时间和启用状态。材料字典的键使用资源ID，如 `wood`、`stone`。
- 保存校验前置存在、级别连续、同占地、循环、训练场景能力、单位、材料和负数成本等。已有建筑ID不直接改名；删除有子级引用的定义会被拒绝，内置建筑受保护。

新定义配置完整后，下次运行游戏自动载入菜单、升级关联和随机池，不必修改HUD里的建筑列表。新行为仍需相应功能场景／脚本；插件不会凭空生成全新战斗AI。

## 训练与升级

民兵营训练民兵；剑士营训练剑士和民兵；弓箭手营训练弓箭手和民兵。同一公共训练脚本按配方执行，保留原任务类型编号与已有场景类名以兼容旧流程。

任务保存申请时的兵种ID、材料费用和训练时长，居民实际走到合法正面、进门后才训练。完成后应用单位数据及军事身份，恢复室外显示和碰撞。取消退款一次，重派保留已经支付的费用和槽位预约；死亡、拆除沿用任务清理。暂停不推进训练。

民兵是训练产生的常驻军事单位，主动迎战，可复用近战、驻军和巡逻；不是将普通居民临时动员成民兵。普通居民与猎人的原战斗职责保留。

首版民兵参数：80生命、5攻击、饥饿增长0.35；训练5木材、10秒、2个槽位。民兵营采用现有营地占位外观，3×3、15木材、15秒施工。升级剑士营为10木材＋10石料，弓箭手营为15木材＋10石料，均20秒；这些是可编辑的初始配置，未进行完整关卡平衡验收。

有训练任务、室内人员或门口排队时禁止升级；升级中禁止新训练、搬迁和拆除源建筑。分支升级复用材料运输和工地施工，取消未开工升级保留原建筑与占地；完工保留生命比例、朝向和镜像，不改变已训练单位的职业。

## 验证边界

- `building_blueprint_test.gd`：T0／T1菜单、真实窗口按钮选择、三选一不重复、重开不刷新、池不足／为空、前置蓝图和新局重置。
- `building_plugin_blueprint_test.gd`：实际创建定义、配置保存读回、模板不被修改、非法配置拒绝及删除；有渲染截图检查。
- `configurable_training_test.gd`：居民实际行走、入屋、民兵／剑士／弓箭手转职及配方快照。
- `blueprint_upgrade_flow_test.gd`：两个分支实际运料与施工、费用、占地、生命比例、取消和升级互斥。测试缩短施工时间，未直接调用竣工。
- `training_reservation_test.gd`：两人槽位预约、重派和取消退款；该测试隔离预约逻辑，实际行走由以上训练回归覆盖。
- `blueprint_game_ui_test.gd`：实际主场景中锁定／解锁分支和多个训练按钮，检查面板不被撑宽、按钮不超出屏幕并保存截图。

训练入口绕障、进门中断、训练显隐／拆除、避难居民转训练、暂停操作和旧防线升级有回归。编辑器独立测试进程退出仍出现扫描／窗口及RID释放告警，不能作为无告警验收；复杂多人拥堵、完整关卡和用户现场仍需试玩。
