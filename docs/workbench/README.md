# 本地游戏 Wiki 与制作工作台

左侧按单位、技能、建筑、标签、资源、关卡、冒险事件和命名浏览游戏 Wiki；左下保留制作总览、待办／问题、新想法、每日日志及关联地图。分类页用图片占位和名称卡片浏览，点击进入单个条目的百科详情。建筑详情按简介、占地、基础属性、建造、升级、训练及相关条目分组，不直接铺开原始 TRES 字段。所有图片目前仅为占位；无介绍的条目标明“暂无介绍”，未解析的数据不猜测。

工作台用于查看游戏数据总览和统筹开发。服务运行期间会监测 data 下的 .tres 与 Script 下的 .gd；Godot 保存配置后，服务等待文件稳定并重建数据快照，打开的网页约3秒内自动刷新。Wiki 不直接写入游戏资源。尚无游戏配置的冒险事件会标注为规划中。
冒险事件页分为“奇遇”和“探险”：奇遇展示地图上额外出现的宝箱营地等条目；探险展示冒险小屋通过热气球或轮船外出的文本冒险规划，当前尚未实现。

## 启动与迁移

安装Python 3.10+，Windows双击`启动工作台.cmd`并保持终端运行；其他系统在本目录执行`python3 server.py`。只使用标准库，无需数据库、Node或联网页面资源。默认选择空闲端口，以终端地址为准，不要直接打开index.html。

程序按自身位置读取上一级docs；正式资料与程序随Git提交后，新电脑安装Python即可启动。用户授权后由助手提交上传，服务不会自动提交Git。换电脑操作见[交接说明](../项目.md#handoff-2026-10-09)。服务只监听本机127.0.0.1。

## 正式资料

[项目](../项目.md) · [系统](../系统.md) · [数据](../数据.md) · [任务](../任务.md) · [日志](../日志.md) · [决策](../决策.md) · [参考](../参考.md)

知识库默认只展示七份主文档；实体、任务和日记在文档内解析，不增加文件。归档按钮按需加载旧资料，只读回查；原文保持原目录结构，工程根引用按原位置解析。
“新想法”单独列出参考.md内未实现的想法，隐藏已实现／取消的记录和归档目录。点击“新增想法”填写标题、内容并保存；点击标题可编辑MD正文。列表中的状态可改为待考虑、暂缓、已实现或取消。记录仍写回参考.md，沿用整份文件哈希校验和历史备份，不会自动创建开发任务。
新增记录保存前重新读取最新资料和编号，保留已填写内容；读取后若文件再次被其他操作修改，仍拒绝覆盖并保留草稿。编辑既有条目不会自动合并外部改动。
想法按大类容器展示，桌面宽屏一行五个大类，窄屏自动减少列数。每个容器内一行一个想法标题，点击进入详情阅读和编辑；状态操作放在详情页。新增时可选择已有大类或填写新大类；分组保存在条目的idea_group元数据中，后续可在MD编辑中调整。
新增想法时，大类以单选按钮展示，再次点击选中按钮可取消选择。选中已有大类后新大类输入框禁用；没有选择时，在文本框填写名称即可创建新大类。两者都为空时不保存。

## 每天收工

助手核对实际工作，更新日志.md内助手总结和验证遗留，保留用户复盘与明日计划；在工程根目录运行：

```sh
python docs/workbench/update_data.py
```

只读`data/**/*.tres`及引用脚本的导出默认值、子资源，更新数据.md快照区，区外手工说明保留。复杂表达式保留原文，不执行GDScript；场景专属参数、增益和实例临时状态不保证覆盖。快照条目只读；服务运行时监测配置保存并自动同步，也可手动运行上述命令。网页“刷新资料”只重新读取MD。

用户在网页点击“刷新资料”，读取最新总结和游戏数据，再填写复盘与明日计划。

## 页面与保存

今日工作台和开发日历读取日志.md日期条目；新增日期仍保存到同一文件。任务看板读写任务.md条目，进度与验证分开。关联图从文档及实体锚点生成一跳关系，最多画18个邻居，完整列表在右侧。

单位对比读取数据.md内玩家及敌方单位，默认选择民兵／剑士／弓箭手，其余可勾选；理论每秒伤害不是实战强弱。手工知识标签不自动成为运行Trait。

编辑条目时合并回所在主文件，检查整份文件哈希；其他条目／外部改动都会拒绝旧版本覆盖。冲突时保留页面草稿，显示最新原文，复制后刷新手工合并。关闭前保存或复制，浏览器草稿不持久化。

覆盖前原字节保存在`.history/相对路径/哈希.bak`，Git忽略本地备份。停止编辑后可复制恢复，跨电脑历史以Git提交为准。服务只写七份主MD，归档、代码和配置只读。

## 边界与检查

支持基础Markdown，不支持完整YAML／GFM、Obsidian双链和附件展示；无多人协作锁、自动提交、全局关系自由布局或多项目切换器。新游戏可复制程序及七文档规范独立启动。

V0.1检查属于旧记录；本次迁移及条目操作检查记录在日志.md。用户体验、跨电脑启动、Godot玩法与性能仍需独立验收。
