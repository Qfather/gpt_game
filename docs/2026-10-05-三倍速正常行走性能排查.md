# 三倍速正常行走性能排查

本轮确认的主要帧耗时尖峰来自迷雾刷新，尤其是视野逐像素合并和对象显隐遍历。尚未完整复现用户现场持续十几 FPS，因此这份结果属于定位证据，不是修复验收。

## 场景与方法

- 从用户当前游戏日志读取据点资源布局种子 `2019318622`。
- 实际 GPU 运行主场景，13 名普通居民、568 个资源、没有敌人；3 倍速。
- 对比无道路、731 格已建土路、仅停用迷雾刷新、暂停。
- 每项预热 20 帧，采样 180 帧；帧耗时采用真实墙钟时间，不使用可能包含初始化耗时的 `Performance.TIME_PROCESS` 旧采样。
- 在测试实例中统计居民、道路查询和迷雾子步骤耗时。没有停止用户游戏，也没有在游戏功能中关闭迷雾或改画质。
- 相同种子不代表完整现场复现：居民位置、建筑布局、工人工作状态和摄像机视野与用户当前游戏不同。

## 实测帧耗时

| 状态 | 平均帧耗时 | 中位数 | P95 | 最慢一帧 |
| --- | ---: | ---: | ---: | ---: |
| 3 倍速，无道路 | 11.72 ms | 8.69 ms | 42.13 ms | 62.50 ms |
| 3 倍速，731 格道路 | 12.60 ms | 8.56 ms | 44.07 ms | 60.45 ms |
| 3 倍速，有道路，仅停用迷雾刷新 | 8.39 ms | 7.72 ms | 14.19 ms | 25.58 ms |
| 暂停 | 8.48 ms | 8.89 ms | 12.49 ms | 13.22 ms |

P95 表示 95% 的帧不超过该耗时。62.5 ms 相当于该单帧约 16 FPS，不能将单帧尖峰描述成持续 16 FPS。

## 耗时来源

有道路的 180 帧采样中，迷雾刷新 22 次，累计 831.39 ms，单次平均 37.79 ms，最大 51.18 ms；无道路时最大 54.02 ms。

| 迷雾步骤 | 累计时间 | 调用次数 | 平均单次 |
| --- | ---: | ---: | ---: |
| 视野逐像素合并 | 495.98 ms | 286 个居民视野 | 1.73 ms/视野 |
| 对象显隐 | 208.07 ms | 22 次刷新 | 9.46 ms/刷新 |
| 树冠显露 | 72.67 ms | 22 次刷新 | 3.30 ms/刷新 |

上述时间是嵌套统计，不应与迷雾总时间重复相加。13 个移动居民的视野会在同一次刷新集中计算，正常走动使缓存持续失效；暂停后视野位置不变，缓存可复用。

道路优先路线在该采样中查询 10 次，累计 20.53 ms，最大 3.63 ms。居民全部物理处理累计 143.58 ms，包含道路查询。道路仍有开销，但这组测试中的主要尖峰来自迷雾。

先优化 `Script/world/fog_of_war.gd` 的 `_reveal_at()` 和 `_refresh_object_visibility()`，并用现有迷雾像素等价、视野缓存、树冠和显隐测试校验行为。不要用降低视野范围或关闭迷雾掩盖问题。

## 本地证据

- `.godot/normal-walk-user-seed.out`：同种子场景分项计时。
- `.godot/normal_walk_probe.gd` 与 `.godot/profile_*.gd`：本次隔离诊断脚本。
- `.godot/speed-profile-current.out`：固定种子 418、13 人的 1／3 倍速对照。
- `.godot/frame-profile-current.out`：116 格待建道路的拖拽／空闲与暂停／播放对照。
- 现有通用测试入口：`Tests/game_speed_performance_probe.gd`、`Tests/road_drag_frame_test.gd -- --with-roads`。

测试退出成功。标准错误中的用户日志写入权限和证书存储提示属于当前测试环境，没有脚本异常。
