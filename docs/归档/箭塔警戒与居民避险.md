# 箭塔警戒与居民避险

2026-10-09将独立瞭望塔合并到箭塔，移除其建筑配置、木结构场景、居民值班岗位与登梯专用状态。

## 警戒与攻击

普通箭塔、木制和石制墙上箭塔统一使用水平20米警戒半径。弓箭手实际登塔并处于驻守状态才生效，预约登塔不算；至少一名有效驻守者即可，全部离塔补粮、进食、休息或塔被毁时暂停。弓箭手原有四处转向表现保留。

警戒半径与射程独立，发现范围内敌人先报警，敌人进入弓箭手原有射程乘塔射程倍率后才射击。选中显示绿色警戒圆，详情显示半径和有人／无人状态。战争迷雾视野仍沿用箭塔原有配置，不把警戒20米直接改成视野或射程。

场景 `Scene/building/game/arrow_tower.tscn` 的 `alarm_radius` 可调整警戒半径，默认20米；墙塔继承同一脚本。保留原驻軍人数、补粮、保护、坠塔晕眩与墙塔升级规则。

## 居民避险

聚落每0.2真实秒统一检查有效箭塔，不随加速重复放大。发现存活敌方单位即报警，敌人离开后保持2秒安全延迟。普通居民不自行遍历敌人组；未受完整城墙保护者回自己的住所，无有效住所则回据点，保留岗位，解除警报后复工。已经入屋的居民等警报解除后再外出。

没有有效警报时，仅实际受击触发普通居民避险，至少保持5秒，已知攻击者仍在附近时继续避险。猎人属于自卫职责，不参加普通居民避险；剑士和弓箭手主动迎战。攻击标签不自动改变普通居民职责，民兵未实现。

城墙保护仅计算完工存活防线闭环，高低差超过0.1米断开，城门按轴向连接，对角漏缝不算封闭；敌人进入某围合区域后，该区暂不豁免避险。墙体变化才重建缓存。城门当前仍可通行，没有开关状态，不能将避险豁免当作城门实际挡敌的验证。

## 验证

`Tests/arrow_tower_alarm_test.gd` 覆盖真实弓箭手登塔、预约不提前警戒、20米边界、射程外不攻击／射程内实际命中、居民实际回屋、无普通居民搜敌、进食暂停、选中范围、墙塔继承、摧毁失效与菜单移除。加 `-- --visual` 记录箭塔警戒截图。

闭环算法使用 `Tests/wall_enclosure_alarm_test.gd`；原箭塔登塔导航、驻军保护、需求预约及猎人进度条使用各自回归。旧性能报告采自旧避险玩法，不能作为合并后大规模帧率承诺；完整关卡和大量箭塔仍需独立压力验证。
