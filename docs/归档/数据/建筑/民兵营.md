# 民兵营

T0开局可建，3×3占地，建造木材15、15游戏秒、最多3名施工者。提供[民兵](../单位/民兵.md)配方：木材5、默认10游戏秒。配置中的旧`training_cost`不替代当前`training_recipes`。

本局获得对应蓝图后可原地升级为[剑士营](剑士营.md)或[弓箭手营](弓箭手营.md)。关联不是额外的地图建成前置规则。
