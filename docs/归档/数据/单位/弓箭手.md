# 弓箭手

远程主动迎战单位，可驻军和巡逻；驻守箭塔时兼任20米警戒。警戒半径不等于攻击射程。

## 来源与默认值

[ArcherData.tres](../../../data/units/ArcherData.tres)指定伤害8、射程8米、间隔1.5秒、侦测12米和箭速18；生命100与移速3取自[UnitData默认值](../../../Script/unit/unit_data.gd)。饥饿增长为0.35。快照未含特性、驻军和实战修正，理论伤害每秒不代表命中收益。
