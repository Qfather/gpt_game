# 民兵

民兵是实际训练产生的基础军人，承担主动迎战职责；不能与尚未实现的“普通居民临时动员”混为一谈。

## 来源与默认值

[MilitiaData.tres](../../../data/units/MilitiaData.tres)覆盖生命80与伤害5；间隔1秒、射程1.5米、移速3来自[UnitData默认值](../../../Script/unit/unit_data.gd)。饥饿增长为0.35。快照未含特性和实际战斗修正，属于静态核对。
