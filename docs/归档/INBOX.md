# 收件箱

[返回首页](HOME.md) · [当前工作](NOW.md)

想法、异常和资料可以先记一行，暂时不用填完整模板。推荐写法：`日期｜内容｜出现条件或来源`。

## 未分类记录

目前没有从旧文档重复复制记录；已知问题见[问题与待验收](知识库/问题与待验收.md)，长期方向见[未来想法](知识库/未来想法.md)。

## 分流规则

- 异常：补充出现条件、实际／预期结果及日志，归问题与待验收。
- 已选定的近期任务：写入当前工作，附完成条件。
- 确认的游戏规则：更新对应系统页；取舍原因归设计决策。
- 灵感：归未来想法；教程与参考保留链接和用途。

每天结束时处理新增条目即可。转入正式位置后保留链接或移除已分流的收件箱条目，避免两处重复维护状态。
