# 狩猎与远程第一版

## 使用入口

1. 建造菜单的生产建筑中放置“猎人小屋”，点击建筑、招募居民；最多两名，居民自动换成猎户外观并开始狩猎。
2. 军事建筑中放置“弓箭手营”，点击“训练弓箭手”；训练期间居民隐藏，完成后出营。
3. 军事建筑中放置“箭塔”，空闲弓箭手或普通军营中待命的弓箭手自动走到塔上；最多两名，不接收剑士和普通居民。弓箭手也能参加普通军营的巡逻与防御，箭塔优先使用待命弓箭手。

## 配置归属

| 入口 | 内容 |
| --- | --- |
| 资源插件底部“建筑” | 猎人小屋、弓箭手营、箭塔的模型、生命、护甲、建造成本、仓储及专属参数 |
| 资源插件底部“单位” | 猎户、弓箭手的模型、伤害、射程、射击间隔、箭矢速度与居民需求 |
| 关卡插件“地图与资源 → 猎物与刷新” | 总数量上限、刷新间隔、距据点生成范围、猎物池、每种猎物的模型／生命／产肉／逃跑速度／权重 |

默认猎物配置嵌入各关卡，点击关卡插件“保存全部”即可保存调整。增加猎物时在池里添加 `PreyData`，指定使用 `Script/world/prey.gd` 的场景。模型默认 +Z 正面、+Y 向上。

## 默认规则

- 兔子：1生命、1肉；野鸡：2生命、2肉；野猪：3生命、3肉。默认猎户每箭1伤害，命中后猎物向远离猎户的方向逃跑。
- 猎户在据点周边巡游，攻击范围内认领一只猎物；其他猎户不会攻击该目标。目标死亡后实际走到旁边拾取，最多背三只；回屋整批处理5–15秒后，肉存入小屋30容量仓储。只有处理后的肉进入资源库存，居民可以吃，移民需求可以计入。
- 小屋满仓时由猎户按资源携带容量取肉送到据点，再回来完成尚未存入的肉；据点肉类容量默认1000。据点满仓时保留手上的肉等待，搬运中离职也先交货、处理剩余猎物，再恢复普通居民。
- 默认地图最多12只猎物，地图与导航就绪后开局生成，不依赖猎人小屋，每20秒补充缺额，实际生成距离据点15–35米，使用安全地面与导航检查。猎户巡游范围35米。尸体也计入上限，未被认领的尸体60秒后清理；猎物遵守战争迷雾，不提供视野。
- 弓箭手默认每箭8伤害、射程8米、间隔1.5秒、箭速18米/秒。箭塔提供1.5倍射程；攻击由实际驻守且未在吃饭或休息的弓箭手发出。
- 箭塔基础视野12米，有一名或两名角色驻守时都为18米，不叠加。默认粮食容量10、低于3启动补粮；一人往返据点，留守者继续射击。补粮员仍占名额，回来自动驻守，补足容量后停止搬运。
- 一人驻守也会自行搬粮，离塔期间恢复基础视野且不发新箭。已射出的箭继续飞行命中。吃粮沿用居民饥饿与喜好机制，不额外重复扣粮。

## 场景

- `Scene/building/game/hunter_hut.tscn`
- `Scene/building/game/archer_camp.tscn`
- `Scene/building/game/arrow_tower.tscn`
- `Scene/unit/hunter_visual.tscn`、`archer_visual.tscn`、`arrow.tscn`
- `Scene/unit/prey/rabbit.tscn`、`pheasant.tscn`、`boar.tscn`

第一版使用基本体，没有射击动画、弹道阻挡或误伤。猎物只在受击时逃跑，猎户承担巡游。

## 自动验证

`Tests/hunting_ranged_test.gd` 在真实主地图验证生成上限与缺额补充、独占认领、箭矢飞行扣血、受击逃跑、拾取三只上限、回屋产肉、解雇恢复、双人射击、补粮期间留守、单人空岗及弓箭手训练显隐。

`Tests/hunting_ranged_editor_test.gd` 验证新增建筑与单位预览、专属字段，以及关卡猎物保存读回与跨关卡隔离。Godot图形进程用于模型截图检查；这些自动检查不代表玩家手动建造与完整40分钟关卡体验已经验收。

本次运行检查与图形预览通过，原训练、驻军防御、军事日常与近战回归通过。测试日志仍包含工程已有的 `HealthLabel` 重名、Flow插件退出及资源释放告警，本次未改动这些问题。
