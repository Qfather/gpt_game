# 项目记录规范

版本：V0.1，2026-10-09。适用于本地知识工作台及后续参与开发的助手。[返回首页](HOME.md)

## 正式数据与目录

Markdown 是正式数据，工作台读取并写回原文件；不另建正文数据库。原历史资料保留原路径。网页程序位于 `workbench/`，运行备份不进入 Git；正式资料随项目由用户选择提交。

| 位置 | 用途 |
| --- | --- |
| HOME／NOW／INBOX | 导航、当前工作和零散线索 |
| 知识库 | 当前系统规则、来源及实现边界 |
| 任务／问题 | 每项独立文件，目标、状态、验收与验证 |
| 日志/YYYY-MM-DD.md | 当日助手总结、用户复盘、验证遗留、明日计划 |
| 数据/单位、建筑、标签 | 一实体一文件，用普通相对链接关联 |
| 既有说明／历史记录／玩法参考 | 原始证据与历史资料，继续保留 |

新游戏可采用相同约定，替换名称、分类和资料；现有旧 Markdown 没有元数据也可以阅读。复制工作台到新项目的 `docs/workbench` 后，项目名称默认取根 README 第一行标题。

## 每天结束的流程

1. 用户明确表示收工后，助手根据本次实际工作先更新当天“助手总结”和“验证与遗留”；必要时更新任务、系统文档及根 README。不能从文件改动自动推断验收通过。
2. 用户进入工作台阅读，填写“我的复盘”及“明日计划”。助手不代替用户编造感受或选定明日目标。
3. 已有用户复盘和明日计划不得被下一次助手总结覆盖。当天补充工作应合并记录，同一长期任务沿用编号。
4. 没有完整证据时记录未确认；历史失败与已修复结果按最新来源区分。旧日志不用重复迁移到新日记。

## 元数据约定

可交互记录在文件开头使用 `---` 包围的元数据。V0.1只解析单行字段：字符串、数字、布尔值；不使用多行值、数组或嵌套映射。正文不受这一限制。字符串含特殊字符时使用双引号和JSON转义。

```markdown
---
kind: task
id: TASK-002
title: "任务标题"
status: 待安排
verification: 未验证
created: 2026-10-09
---

# 任务标题

## 目标与范围

## 验收条件

- [ ] 具体、可观察的完成条件

## 验证记录
```

- `kind`：`task`任务、`issue`问题、`journal`日记、`unit`单位、`building`建筑、`tag`知识标签；普通文档无需填写。
- 任务／问题：必须有 `id`、`title`、`status`、`verification`。编号稳定、全项目同类唯一，TASK／BUG前缀；编号不随标题改变。
- 进度：待安排、进行中、待验收、已完成、阻塞、取消。已完成需满足验收条件，取消说明原因。
- 验证：未验证、通过、部分通过、失败。正文必须附方式、版本／日期、范围、结果及剩余边界；切换进度不自动改变验证。
- `journal`必须有`date: YYYY-MM-DD`，正文沿用四个二级标题：助手总结、我的复盘、验证与遗留、明日计划。
- `unit`对比字段：`unit_id`、`health`、`attack`、`attack_interval`、`attack_range`、`move_speed`、`role`、`checked`。未知值省略，不能拿0代替未知。
- 原始配置的路径、基础数值继承／默认值、核对日期与修正边界写在正文。MD 是配置的知识快照，编辑它不会修改游戏数据；改游戏配置后应同步更新快照。

## 关联方式

使用普通 Markdown 相对链接连接实体与系统，例如单位正文链接到训练建筑，建筑正文链接回训练单位；标签文件解释其含义。工作台自动显示引用、反向引用及直接关联地图。

“知识标签”可以描述职责、类别等概念，不自动等于游戏里已实现的 `UnitTrait` 或 Trait资源。运行特性应明确写出实际配置来源和效果。不要把分析分类说成已实现机制。

V0.1不依赖Obsidian专用语法。暂不支持`[[双链]]`、嵌入引用、完整YAML或Markdown扩展语法；代码、表格、标题、普通链接和基础列表可阅读。

## 写入与协作

- 助手修改前读取本规范、相关系统页与当前任务；改动后分别记录当前规则与历史证据。
- UI保存前核对读取时的文件内容哈希；外部改动发生时拒绝覆盖，保留页面草稿、显示最新文件供手动合并。刷新／关闭前先复制未保存内容。
- 保存原文件前保留本机旧版本，位置`workbench/.history/`；这是辅助恢复，不替代Git。服务器仅写docs内MD，不修改游戏配置或代码。
- Git提交、上传由用户决定，工作台不自动执行。跨电脑使用需要把正式资料和程序一并提交，并在新电脑安装Python 3.10及以上。
