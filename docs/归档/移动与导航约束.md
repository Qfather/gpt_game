# 移动与导航约束

适用居民、军人、猎人、敌人和移民的移动，以及采集、运输、施工、道路、训练、驻军、生活需求和避难流程。工程级规则见 [AGENTS.md](../AGENTS.md)。创建于2026-10-09。

## 状态与判定必须分开

| 判定 | 含义 | 不能推导出的结果 |
| --- | --- | --- |
| 找到路径 | 导航返回一条路线 | 角色已到达、通道没有动态障碍 |
| 目标可达 | 当前导航模型能连通目标 | 真实碰撞一定允许通过 |
| 路径结束 | 代理走完路线或进入停止距离 | 抵达真实交互区域、可以交付资源 |
| 实际到达 | 角色位置、高度和目标交互区域符合规则 | 任务和建筑引用仍有效、岗位一定有空位 |
| 可开始交互 | 实际到达且任务、对象、通道和预约仍有效 | 可以略过玩家暂停、立即完成整个流程 |
| 暂时停滞 | 一段时间未取得足够移动进展 | 永久不可达、应放弃资源或任务 |

任何状态切换都不能跳过对应的实际条件。路径末端在建筑外时不隔空卸货；目标位于另一高度时不隔层攻击、采集或施工；已到工地也要区分运料位置和施工位置。

## 入口与碰撞

1. 建筑入口、正面宽度和朝向应从公共建筑接口获得，不由职业代码再猜一套坐标。旋转、镜像、搬迁后使用有效世界坐标；正面区域不包含建筑背面和错误楼层。
2. 点位可达和入屋通道畅通分别检查。候选点之外，进入建筑前的路径也不能穿过相邻建筑、资源或防线；不能绕路到了侧边又动画拉回被挡住的中央门点。
3. 门口容差与导航停止距离、角色实体尺寸协调。不能只扩大点击区域或入口区域来遮盖失配；全封闭、不同高度、背面和侧面作为反例验证。
4. 建筑静态碰撞、导航障碍、单位动态碰撞／避让和模型显示分别看待。外观重叠不必然等于实体卡住，导航区域也不必然和模型轮廓相同。
5. 进出屋队列串行处理，进门前验证身份与建筑状态；取消、离岗、死亡及建筑删除后清理队列与室内名单。不能以关掉碰撞制造多人穿门或穿邻近建筑的假成功。

## 停滞恢复顺序

1. 检查是否已实际到达；到达后结束移动，不因停止移动继续触发恢复。
2. 尚未到达时持续监测有效进展，包括路径已结束的情况。小幅往返、外观回弹和高度抖动不等于实际前进。
3. 到恢复间隔后先验证目标、任务和导航状态；过期目标清理并转入明确的后续状态。
4. 有效目标重新查询路径；建筑入口受阻时按同一公共规则尝试其他正面位置。记录恢复后的真实移动，不能只检查“重查函数被调用了”。
5. 若通路仍不可用，保持合理等待／不可达提醒，后续按间隔或障碍变化重试。不能每帧全图查询，不能直接把资源入库、任务完成或角色移到室内。
6. 资源、材料与岗位按当前任务规则保留／释放；自动恢复不能产生重复认领、额外工人、丢失货物或任务抖动。

当前实现中存在约1.5游戏秒停滞计时、0.2米有效移动和部分入口重试间隔。这些是现有实现值，不是永久标准；修改时核实角色速度、尺寸、导航停止距离及1／3倍速表现，并用反例验证。

## 修改前检查

- 记录角色状态、真实位置、导航目标／末端、路径是否结束、建筑正面、碰撞对象、任务与货物。截图无法确认的数据不自行编造。
- 判断属于到达失配、实体碰撞、动态拥堵、过期导航、非法目标还是异步回调；不要看到感叹号就一律扩大入口。
- 检查共享调用链，以及训练、工作、避难、移民、驻军、资源和返程是否使用相同有缺陷的判断。
- 定义成功条件：实际走到合法交互区域、完成真实交互、恢复原任务，且在反例中不会穿墙、提前交付或错误完成。

## 按修改范围选择回归

不要求每次跑所有测试；公共移动、碰撞和入口规则变化必须覆盖受影响的调用流程。

| 改动 | 必须包含的情形 | 现有入口参考 |
| --- | --- | --- |
| 入口／到达 | 正面中央及两端、背面／侧面拒绝、不同高度、停止距离边缘、四向旋转和镜像 | `Tests/building_front_entry_test.gd`、`Tests/entrance_triangle_test.gd` |
| 工作建筑／运输 | 邻近建筑挡住原入口仍有替代位置、完全不可达不卸货、货物实际入库、任务继续 | `Tests/lumber_workplace_entry_test.gd`、`Tests/workplace_edge_repath_test.gd` |
| 训练／驻军 | 相邻箭塔堵住入口、实际入屋、训练开始、名额预约、途中取消／销毁 | `Tests/training_neighbor_obstacle_test.gd`、`Tests/training_door_interruption_test.gd`、`Tests/arrow_tower_entry_navigation_test.gd` |
| 建筑碰撞／公共移动 | 起点靠近建筑角落、途中建拆、绕障而不穿实体、路径结束但未到达、微幅抖动、恢复间隔 | `Tests/building_collision_navigation_test.gd`、`Tests/workplace_edge_repath_test.gd` |
| 避难／生活需求 | 农舍及住宅正面进入、多人排队、住所失效、进出屋后恢复岗位或待命 | `Tests/farm_shelter_entry_test.gd`、`Tests/shelter_front_approach_test.gd`、`Tests/indoor_idle_rest_test.gd` |
| 道路／巡逻 | 地面高差、路角、狭窄通道、任务结束返程、多人集合和队列 | `Tests/road_construction_test.gd`、`Tests/barracks_patrol_group_test.gd` |
| 性能／恢复频率 | 1／3倍速，多单位同时受阻，记录查询次数和长帧，确认未变成每帧重查 | `Tests/fog_raid_stress_test.gd`；另补与当前改动对应的拥堵布局 |

测试列表是选择入口，不是“已全部通过”的清单。邻近障碍用实际实体和导航验证，至少覆盖入口部分受阻及全受阻；涉及多人恢复时必须增加多人案例。图像、动画和可见穿模另做有渲染检查。

异步进门、卸货及退出岗位完成后再断言资源和状态。不能人为摆到终点或直接切换完成状态来验收移动。测试布局调整须解释为何不再代表原验证目标，不能消除用户报告的障碍来宣称问题解决。

## 当前实现边界与后续工作

- 公共入口接口在 `Script/building/BuildingBase.gd`；居民通用移动及停滞恢复在 `Script/unit/game/villager.gd`；道路路线在 `Script/unit/road_navigation.gd`；动态避让在 `Script/unit/unit_avoidance.gd`；导航构建在 `Script/world/map_generate_runtime.gd`。
- 敌人、移民、居民战斗／避难等仍有各自流程。**本文件建立约束，不代表所有流程已经统一，也不授权本轮自动重构这些模块。** 后续修改逐项检查并把同类不变量落实到公共代码与测试。
- 2026-10-09工作建筑边缘、路径结束及微幅抖动恢复有回归；用户截图中的原布局尚未直接复现。旧道路施工测试仍有断言失败，应保留并核查，不删除或声称全工程通过。
- 新增或改变单位类别时，重新核实攻击能力与职责、实体尺寸和交互方式。不能默认“有攻击力就主动迎战”，也不能默认“所有单位可用同一到达半径”。

交付记录必须写明：复现条件、实际修改、通过的测试、失败／未验证项、性能和玩法变化，以及是否需要重启游戏或用户现场确认。
