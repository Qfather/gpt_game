# 单位编辑器第一版

入口为 Godot 编辑器底部的 **“单位”** 标签，归于现有 `resource_editor` 资源插件。未出现时重新启用“资源”插件或重开编辑器。

左侧列出居民、剑士、弓箭手、猎户，以及 16 份现有袭扰／裂缝敌人配置，并统一显示方形模型预览。选择单位后在右侧修改参数，点击“保存单位配置”。

| 配置 | 保存位置 | 运行用途 |
| --- | --- | --- |
| 居民 | `data/units/ResidentData.tres` | 初始居民、移民入住后的居民，以及普通居民的工作、搬运与需求参数 |
| 剑士 | `data/units/SwordsmanData.tres` | 训练成为剑士后应用的独立参数；驻军、巡逻、防御与寻宝继续走现有行为 |
| 袭扰／裂缝敌人 | `data/enemies/raid/` 与 `data/enemies/rift/` 中原有 EnemyData | 关卡出怪、营地守卫与手动投放继续引用原资源 |

## 模型朝向约定

单位外观统一为 **+Z 正面、+Y 向上**，预览相机从 +Z 一侧拍摄。现有九个敌人模型已将视觉部件旋转到该约定，保留根节点及原有缩放、材质和尺寸。新模型请在外观场景内校正朝向；居民与剑士已使用基本体人形外观；居民为棕色衣服，剑士为银色护甲、红色衣服并携带剑盾。相机自身的前方仍为 −Z。预览在切换或刷新时重新读取模型文件，避免编辑器保留旧场景造成朝向显示不一致；模型场景页尚未保存的修改需先保存。

## 可编辑内容

现有单位采用统一的方块基本体风格：弓箭手穿蓝绿色衣服，猎户穿绿色衣服，均携带弯弓和箭袋；敌人保留各自体形、武器与 Boss 特征。模型颜色与原材质颜色相乘，预览和游戏保持一致。

游戏中居民和怪物的外观放在 `VisualRoot` 下，由行为控制其水平朝向；移动时面对移动方向，采集和攻击时面对目标。以每秒 450° 沿最短角度平滑转身（90° 用 0.2 秒、180° 用 0.4 秒），正后方固定选择同一侧，转身期间继续移动。替换模型时保持 +Z 为正面、+Y 为上方，模型内部的骨骼动画独立播放，动画不要直接控制外层 `VisualRoot` 的旋转。若以后使用根运动，需要再协调动画位移与现有导航移动。

居民职业配置包含名称、说明、外观场景、模型颜色、生命上限、生命恢复基础值、移动速度、工作／采集倍率、采集数量与间隔、资源携带容量、攻击伤害／距离／间隔／索敌范围，以及饥饿、疲劳和休息恢复速度。

敌人配置沿用 EnemyData，包含外观、战斗、阵营、Boss 标记、技能、特性与袭扰目标等原字段。关卡编辑器继续负责出怪编组和时间线，单位页负责其引用的敌人属性。

- 外观留空时居民／剑士使用原胶囊模型，敌人使用原球体占位模型。可选择纯 3D 模型场景或 GLB，保留原单位导航、点击碰撞和血条；模型颜色为白色时保留外观场景原材质。
- 居民与剑士使用同一个行为场景，以职业选择对应配置。普通居民即使有攻击参数也不主动参战，职业判定沿用现有规则。
- 转职保留生命比例，而非恢复满血；同时保留个人标签、饥饿、疲劳和人口身份。改变角色外观不会生成新的居民。
- 配置中的名称会显示在游戏单位信息面板中，场景节点名称仍保留。
- 原数值保留：居民／剑士生命 100、移动 3、资源携带 5；剑士伤害 10、攻击距离 1.5、间隔 1 秒、索敌 10。单位护甲和射箭规则未在此阶段新增。
- 生命恢复基础值沿用现有属性读取接口，本阶段不新增自动回血规则；技能／标签改变属性的规则也沿用原系统。

## 保存规则与范围

- 修改先保存在副本中；切换或刷新会放弃未保存修改，点击保存才写入当前资源。
- 稳定 ID 只读。单位列表按实际资源文件扫描，敌人按袭扰／裂缝分类，即使名称相同也可区分。
- 保存拒绝非法生命／移动／攻击间隔、负攻击／范围、无效工作采集携带数值、负需求速度及非 3D 外观场景。居民职业的移动和间隔必须为正；敌人保持原导出范围，允许零移动速度和零攻击间隔。
- 敌人属性影响所有引用它的关卡与营地。不要同时在多个编辑器中保留同一资源的未保存修改，避免相互覆盖。
- 保存用于下次运行和后续应用配置的单位；不对已经运行的单位进行热更新。
- 后续已接入猎户、弓箭手、箭矢、猎物生成、猎人小屋和箭塔，参数继续在同一编辑器管理，详见 [狩猎与远程第一版说明](狩猎与远程_第一版说明.md)。

## 验证

`Tests/unit_editor_test.gd` 使用图形设备在编辑器模式检查 18 份配置的网格预览、编辑隔离、非法间隔拒绝、模型及参数保存读回，生成 `.godot/unit_editor_preview.png`。

`Tests/unit_editor_runtime_test.gd` 在实际地图读取保存副本，验证生命 175、移动 4.4、携带 8、伤害 17、需求速度和外观生效；保留导航／点击与模型原材质，实际攻击扣除 17 生命；转回居民时保持生命比例并保留喜好标签，游戏面板显示配置名称。测试只写 `.godot/` 副本，不改变正式平衡数值。

原军事日常、据点受击防御、训练隐藏、阶段移民、战斗及建筑编辑器运行回归通过。编辑器退出仍有原有 Flow Graph 和资源释放告警；此阶段不代表射箭玩法已经实现。
