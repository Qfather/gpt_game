## 地图与游戏怎样分工

`addons/MapGenerate` 是独立子模块，负责地形轮廓、高度、模型库、植被和通用地表数据。游戏侧 `Script/world/map_generate_runtime.gd` 接入关卡配置、可采集资源、网格、导航和建筑影响。

手动设置、自动生成和模型库各有职责；`cell_size_m` 缩放输出，不修改原模型资源。地图重建、障碍变化和缓存失效不能混为一谈。当前导航变化已合并请求并异步烘焙，不应把“改成异步”再列作未实现任务。

来源：[地图插件 README](../../addons/MapGenerate/README.md)、`Script/world/map_generate_runtime.gd::_rebuild_navigation_async()`、[工程约束](../../AGENTS.md)。

## 资源和植被

可采集树石由关卡资源条目控制地形权重、簇、精确间距、湿润度、生长与再生。成熟资源阻挡导航；幼苗与成熟的碰撞生命周期不同。再生遵守建筑、蓝图、道路与通道，不能强凑数量。

装饰植被由地图插件生成，种类权重、模型比例、适湿范围与范围外概率各有含义；有限候选不保证目标数量或最终出现比例。游戏迷雾覆盖植被，植被不因此成为视野源。

来源：`Script/world/map_resource_entry.gd`、`map_generate_runtime.gd`、`Script/resource/ResourceBase.gd`、[插件 README](../../addons/MapGenerate/README.md)、[历史生长再生记录](../历史记录/开发记录_截至2026-10-07.md)。独立森林占格演示仍是实验，不代表正式生成已迁移。

## 昼夜与迷雾

主场景已使用 `StylizedDayNight`；实际是自定义昼夜天空、太阳／月亮、星星和云，而非旧计划要求的静态白天 `ProceduralSkyMaterial`。游戏订阅夜间倍率，白天倍率为 1。独立 `lens_effects` 演示没有接入主游戏。

战争迷雾维护当前视野、探索记录和显示贴图，含树遮挡、树冠表现及对象显隐。当前有角度、像素和对象子节点缓存；不能说刷新已没有 CPU 成本。旧天空 README 尾部“夜间倍率未接入”与其顶部更新矛盾，当前接入以 `Script/main.gd`、[开发记录](../历史记录/开发记录_截至2026-10-07.md)和[天空插件说明顶部](../../addons/stylized_day_night/README.md)为依据。

## 道路与实际通行

土路／石路支持拖拽、居民施工、升级、拆除、按配置增加移速和道路优先路线；未完成路段不提供加速。材质与贴图按连接形态处理，合并分块网格；道路查询已有预算，不是无约束逐帧全图寻路。

2026-10-09新增沿行进方向走右半幅中心，1 米路宽偏移 0.25 米，转角连接偏移线；右侧被导航阻断时回退普通导航，不偏移建筑入口。自定义单位主动避让随后暂时停用，实体碰撞保留。敌人和移民普通导航不能自动当作同一套道路靠右能力。

来源：`Script/world/road_manager.gd`、`Script/unit/road_navigation.gd`、`Script/ui/road_tool.gd`、`data/buildings/DirtRoadData.tres`、`StoneRoadData.tres`、[开发日志](../开发日志.md)。道路尚未接入存档。
