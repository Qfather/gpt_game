## 保存规则已经变化

旧建筑／单位第一版说明写“点击保存才写入”，后续已有自动保存接入记录。当前建筑通用配置保存 `BuildingData`；只有专属参数变化才写功能场景，避免无意义重写打开的场景。切换和重载行为以当前插件为准。

来源：[2026-10-07 保存范围记录](../开发日志.md)、`addons/resource_editor/building_editor_panel.gd`、[历史自动保存记录](../历史记录/开发记录_截至2026-10-07.md)。不把旧手动保存说明当作最新完整操作手册。编辑器退出警告及排版仍有边界。

## 模块化建筑生产管线

旧方案描述 Blender 搭装模块 → GLB 模块标识 → Godot 模块数据库转换 → 施工阶段逐块出现 → 损坏／维修模块表现。

现有工具能按桥接 GLB 的空对象组选择模型并批量替换；这只能证明部分桥接能力存在。当前没有找到足够证据确认 `ModuleDatabase`、`build_stage/build_order` 到正式建筑施工的完整集成，也未验证转换后坐标和模块复用。`bl/` 源资产存在不代表已接入运行建筑。

来源：[Blender 管线计划](../Blender_to_Godot_模块化建筑生产管线.md)、上述桥接脚本、`Script/construction_site.gd`、[开发日志](../开发日志.md)。该计划适合继续当美术方案；不应整体标记“已完成”或“完全未做”。
