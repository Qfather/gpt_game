## 谁会战斗

| 身份 | 当前职责 |
| --- | --- |
| 普通居民 | 警报／受击触发避险；有攻击加成不自动参战 |
| 猎人 | 自卫，战后恢复狩猎、返程或处理流程 |
| 民兵、剑士、弓箭手 | 训练产生的军事单位，主动迎战，可接入驻军／巡逻与营地接口 |
| 箭塔驻守者 | 只接收有效弓箭手；普通箭塔最多两名，墙上塔楼一名 |

攻击能力与职责分开，民兵训练已经实现；“普通居民临时动员为民兵”仍未实施。来源：`Script/unit/combat_role.gd`、`Script/unit/game/villager.gd`、`data/units/MilitiaData.tres`、[工程约束](../../AGENTS.md)。

## 公共训练与驻军

建筑配置多个 `TrainingRecipe`，任务保存申请时的目标单位 ID、费用和时间快照。居民实际到正面、排队进门后计时，完成应用单位数据并出门；取消、重派、死亡及拆除处理费用和槽位。当前训练是居民转职，不是炮车等独立实体生产。

民兵营训练民兵；两个高级分支分别保留民兵和剑士／弓箭手配方。军营安排驻军、军粮补给、生活需求和巡逻；箭塔攻击由实际驻守弓箭手发出，吃饭休息／离塔影响岗位是否有效。

来源：[公共训练说明](../建筑蓝图与公共训练.md)、`Script/training_recipe.gd`、`Script/building/game/swordsman_camp.gd`、`barracks.gd`、`arrow_tower.gd`。

## 警戒、攻击和战争迷雾

驻守弓箭手兼任水平 20 米警戒，敌人进入原射程才攻击；这不把射程或迷雾视野扩大成 20 米。独立瞭望塔已移除。普通居民固定回住所，无家回据点；完整防线保护可豁免，缺口、高差、错误连接或敌人进入围合区会取消保护。

来源：[箭塔警戒与居民避险](../箭塔警戒与居民避险.md)、`Script/world/settlement_alarm.gd`。闭环保护是规则判断；城门开关未实现，不应说闭环已经绝对挡敌。

远程箭矢已有飞行命中和后续抛物线表现；普通受击回弹仅移动外观，不移动真实角色。技能力效果与普通受击反馈分开，见[工具与技能页](内容工具与美术.md)。

## 宝箱营地

合法的当前无视野区域生成营地；允许已探索但目前不可见的区域。守卫、奖励在生成时确定。探索后可点击营地面板，安排合法战斗单位前往清剿；撤回／结束恢复原有军事流程。清空守卫后才发布居民搬运任务，实际卸货增加库存；搬空后营地移除。

来源：`Script/world/camp_spawn_manager.gd`、`treasure_camp.gd`、`camp_guard.gd`、`loot_bundle.gd`、`UI/camp_panel.gd`、[营地原说明](../宝箱营地_第一版说明.md)。旧原说明的默认主关卡 `LevelFlow_V0` 已被困难预设替代；配置数字需看当前关卡。

**营地过渡碰撞 BUG 已有修复记录。** `can_accept_treasure_hunt()` 拒绝初始出门、未完成待命站位和进出门过渡；UI与实际入口共用判断。撤回不恢复临时零碰撞掩码。本轮核对了当前 `villager.gd` 对应条件；无界面与 D3D12 整链路通过是同日已有记录，非本轮重跑。来源：[营地修复结果](../营地回归失败排查_2026-10-09.md)、[开发日志](../开发日志.md)。

## 三方与关卡主线

我方、袭扰方、裂缝方由阵营关系和配置控制。袭扰目标、偷窃／破坏等已有实现；营地守卫活动范围与普通袭扰行为有区别。不能因为旧设计提过 `BehaviorProfile` 就说完整行为编辑器已经存在。

`EncounterDirector` 排时间线，`RaidSpawnManager` 和 `RiftManager` 分别执行。主预设名为 40 分钟困难关卡；原说明记录 27 个事件和 202 名计划敌人，本轮未重新计数当前资源。这是预设说明中的数量，不是实际一局保证出场数量。

最后一个按基础出场时间识别的裂缝 Boss 事件完成才胜利；中场 Boss 或袭扰 Boss 不提前结束游戏，据点被毁失败优先。40 分钟开始关底倒计时，旧裂缝可令事件顺延，不是到时强制胜利。

来源：[40 分钟关卡](../40分钟困难关卡说明.md)、[Boss 胜利条件](../BOSS_V0_关卡配置与胜利条件.md)、`Script/world/encounter_director.gd`、`Script/world/rift_manager.gd`、`Script/game_state.gd`。
