Windows GUI 引擎直接调用可能提前返回、输出不完整。需要可靠等待和保存输出时，可逐个测试使用下列方式（GPU 测试删去 `--headless`）：

```powershell
$taskOut = Join-Path $taskProject '.godot/handoff-road.out'
$taskErr = Join-Path $taskProject '.godot/handoff-road.err'
$taskProcess = Start-Process -FilePath $taskGodot -ArgumentList '--headless','--path',('"' + $taskProject + '"'),'--script','res://Tests/road_system_test.gd' -WindowStyle Hidden -PassThru -RedirectStandardOutput $taskOut -RedirectStandardError $taskErr
$taskFinished = $taskProcess.WaitForExit(60000)
if ($taskFinished) { $taskProcess.ExitCode; Get-Content $taskOut; Get-Content $taskErr }
```

先完成编辑器首次导入，使 `.godot` 目录存在。每个测试单独运行、检查退出码和错误输出；不要用日志文件存在代替测试通过。GPU 测试还需检查画面。

部分测试依赖编辑器测试提前生成的 `.godot` 临时资源，例如 `unit_editor_runtime_test.gd` 读取 `unit_editor_swordsman.tres` 与 `unit_editor_enemy.tres`；不带缓存时不能直接宣称全套测试可运行。不要将旧测试夹具混入正式 `data`。
